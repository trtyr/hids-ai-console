## 二、本卡定下的对外契约（测试照这个写）

### A1 `GET|PUT /api/wiki/pages/{pagePath}`：404 只给相对路径

| 情形 | 状态码 | 正文 | 判据 |
| --- | --- | --- | --- |
| 路径语法合法、文件不存在 | 404 | `{"error":"知识库页面不存在：<相对路径>"}` | `wiki-store.js:75-83` |
| 路径语法非法（目录不在白名单、文件名不合规） | 400 | `{"error":"知识库页面路径无效"}` | `wiki-store.js:32-39`（未变） |
| 页面存在 | 200 | 页面对象（`content` 等，未变） | `wiki-store.js:82` |

- **承诺**：404 正文**不含**服务器绝对路径（不含 wiki 目录、不含 `/home/`）。GET 与 PUT 同一口径（PUT 内部经 `get()`，`wiki-store.js:162`）。
- **可断言**：正文严格等于 `{"error":"知识库页面不存在：common/GEN-99.md"}`；且 `!body.includes(<wiki 目录>)`。
- 页面不存在时写接口的响应**优先级**：先校验 `expected_revision`（400 缺版本），再 404。

### A2 `GET /api/agent/triage/status`：syslog 模式新增 `syslog` 对象

`input_mode === 'syslog'` 时 200 正文多一个键（其余键不变）：

```json
{"initialized":true,"enabled":true,"input_mode":"syslog","last_poll_at":null,"last_error":null,
 "counts":{"queued":0,"running":0,"done":0,"failed":0},
 "syslog":{"listening":false,"bind":null,"error":"bind EADDRINUSE 127.0.0.1:15599"}}
```

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `syslog.listening` | boolean | 进程是否真的绑上了 UDP 端口；`false` = 这条 syslog 输入一条消息也收不到 |
| `syslog.bind` | string \| null | 绑上时的 `udp://<address>:<port>` |
| `syslog.error` | string \| null | 绑定失败的原因（截 300 字），如 `bind EADDRINUSE 127.0.0.1:15514` |

- 三态可区分：**未尝试绑定** `{listening:false, bind:null, error:null}` / **绑上** `{true, "udp://…", null}` / **绑定失败** `{false, null, "<原因>"}`。
- `input_mode === 'poll'` 时**不出现** `syslog` 键，仍出 `interval_ms`（形状与改动前一致）。
- 绑定失败**不影响** HTTP 服务与队列：`enabled`、`counts` 照常。

- **重映射脚本（本轮跑的原文，可复跑）**：

```python
#!/usr/bin/env python3
"""把文档里的 文件:行号 从基准 commit 机械重映射到目标 commit（按 git diff 的 hunk 计算位移）。"""
import re, subprocess, sys

BASE = '35530d8'

def hunks(path, base=BASE, head='HEAD'):
    diff = subprocess.run(['git', 'diff', '-U0', f'{base}..{head}', '--', path],
                          capture_output=True, text=True, check=True).stdout
    out = []
    for line in diff.splitlines():
        m = re.match(r'^@@ -(\d+)(?:,(\d+))? \+(\d+)(?:,(\d+))? @@', line)
        if not m:
            continue
        old_start = int(m.group(1)); old_count = int(m.group(2) or 1)
        new_start = int(m.group(3)); new_count = int(m.group(4) or 1)
        out.append((old_start, old_count, new_start, new_count))
    return out

def mapper(path):
    hs = hunks(path)
    # 只算真正改变行数（或行内容被替换）的偏移：length 变化的 hunk
    def map_line(n):
        delta = 0
        for old_start, old_count, new_start, new_count in hs:
            if n < old_start:
                break
            if old_start <= n < old_start + old_count:
                # 落在 hunk 内：按位置映射；删除行映射到 hunk 之后的第一行
                offset = n - old_start
                if offset < new_count:
                    return new_start + offset
                return new_start + new_count
            delta += new_count - old_count
        return n + delta
    return map_line

def remap(path, code_files):
    text = open(path, encoding='utf-8').read()
    maps = {f: mapper(f) for f in code_files}
    stats = {'changed': 0, 'same': 0}
    samples = []

    def repl(m):
        file, start, end = m.group(1), int(m.group(2)), m.group(3)
        if file not in maps:
            return m.group(0)
        f = maps[file]
        new_start, new_end = f(start), f(int(end)) if end else None
        if new_end is None:
            new = f'{file}:{new_start}'
        elif new_end == new_start:
            new = f'{file}:{new_start}'
        else:
            new = f'{file}:{new_start}-{new_end}'
        if new == m.group(0).replace(' ', ''):
            stats['same'] += 1
        else:
            stats['changed'] += 1
            samples.append((m.group(0), new))
        return new

    pattern = re.compile(r'([A-Za-z0-9_./-]+\.(?:js|yaml)):(\d+)(?:-(\d+))?')
    new_text = pattern.sub(repl, text)
    return new_text, stats, samples

if __name__ == '__main__':
    write = '--write' in sys.argv
    targets = {
        'docs/modules/http-api.md': ['server.js'],
        'docs/modules/knowledge-base.md': ['wiki-store.js', 'wiki-workbench.js', 'wiki-replay.js'],
        'docs/modules/triage-pipeline.md': ['triage-monitor.js', 'syslog-input.js', 'syslog-case.js'],
    }
    todo = [a for a in sys.argv[1:] if not a.startswith('--')]
    for doc, files in targets.items():
        if todo and doc not in todo:
            continue
        new_text, stats, samples = remap(doc, files)
        print(f'== {doc}: changed {stats["changed"]} / same {stats["same"]}')
        for old, new in samples[:8]:
            print(f'   {old} -> {new}')
        if write:
            open(doc, 'w', encoding='utf-8').write(new_text)
```
