**A2：syslog 匹配不上时日志带「哪条规则、差在哪」**

四条 `rule` 各有用例（`node --test evidence/test/P003-T027/logging.test.js`）：

- `msgid_map`：未映射的 MsgId → `{rule:'msgid_map', msgid:'cloudwalker-unknown-type', reason:'该 MsgId 尚无牧云事件类型映射'}`
- `payload`：缺 `host_ip` / 缺 `event_time` 两例 → `{rule:'payload', missing:['host_ip']}`、`{..., missing:['event_time']}`
- `event_id`：牧云返回 `{id:9, host_id:2, host_ip:'10.0.0.6'}` 对 syslog 的 `{event_id:7, host_id:1, host_ip:'10.0.0.5'}` → `mismatch` 三项逐项 `{wanted, returned}`
- `time_window`：候选都在 600/900 秒外 → `{rule:'time_window', window_seconds:300, candidates:2, nearest_gap_seconds:600}`；`listEvents` 抛错 → 同 rule + `reason:'牧云事件查询失败：rpc timeout'`

**A3：日志不出现 Token 和密码**

- 真实路径用例：让 `listEvents` 抛 `GET /api/v1/host/list?api_token=SECRET123456 failed, password=hunter2, Authorization: Bearer abcdef123456`，断言落盘原文里 `SECRET123456` / `hunter2` / `abcdef123456` 一个都没有、且出现 `[redacted]`（脱敏闸在 `log.js:9-22`，本卡没绕过它）。
- 生成密钥用例：断言日志原文里没有 `BEGIN … PRIVATE KEY`、没有 `[A-Za-z0-9+/]{60,}` 这种 base64 正文、没有 `content` / `privateKey` / `encryptionKey` 键。
- `HIDS_UPDATE_*` 的取值、`HIDS_MAINTENANCE_PASSWORD` 一律不进新事件（只记路径、版本、序号、环境标识、MsgId、主机 IP、原因）。
