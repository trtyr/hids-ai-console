### 本卡定下的语义（openapi 已同步）

| 情形 | 状态码 | 判据 |
| --- | --- | --- |
| 告警 ID 非法 / 事件类型不在枚举 | 400 | 路由层校验，不变 |
| 牧云可达、但这条事件读不到 | 404 | GetEvent 报错但同类列表探得通，或 result 里没有事件身份 |
| 牧云不可达 | 502 | GetEvent 与同类列表都失败（原错文案上抛） |
| 上游返回别的事件 ID（自相矛盾） | 502 | 不归 404：说明查到了事件，只是不是这条 |
| 未配置牧云 | 503 | 不变 |

`TriageCase.evidence[]` 元素固定四字段：`evidence_id` / `tool` / `fetched_at` / `sha256`（44 + 64 位哈希），未配置研判或仍在排队时为空数组。`/api/alerts` 顶层 `triage_configured` 为 false 时 `alerts[].triage` 恒为 null，`triage_status`/`verdict` 筛选按「无记录」口径。
