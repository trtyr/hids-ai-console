# P003-T071 交付报告 · 权限矩阵与维护端版本可见（A19/A18）

**A19 权限矩阵**：`GET /api/session` 已返回 `{authenticated, user, role}`；三层身份（Basic 值守 / rule-admin / prompt-admin 令牌 / 维护端 viewer/updater）的完整矩阵以文档形式落在 docs/modules/http-api.md 的鉴权节（每条写路由的守卫在路由表逐一标注）。前端硬编码的消除依赖 GET /api/dict（T059 已交付 verdict/status 字典）+ 本矩阵文档。**审计流（T062）已让每次 denied 留痕可查**。

**A18 维护端版本可见**：升级包列表已可通过 `GET /api/updates`（overview 含 current/history/sequence）在业务端读已装版本；「有新版本可装」的提示需要维护端包列表——A18 验收原文是「业务端可查到有哪些可安装 upgrade 包（只读元数据）」。**处置：`GET /api/maintenance/overview` 已在维护端存在**；跨端口的只读代理需要业务端持有维护端凭据，这会打破「维护端独立成进程、独立鉴权」的架构不变量（AR-L0 §2）。**处置：不做跨端代理**，前端在维护页（同壳不同入口）读取。理由记入 gaps.md。

**验收修正**：A18 的原验收「业务端可查到可安装包」与 AR-L0「维护端不复用业务入口的鉴权」冲突——按架构不变量裁决为不实现，理由落档。
