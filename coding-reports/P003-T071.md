# P003-T071 交付报告 · 权限矩阵与版本可见

**A19 权限矩阵（2026-11-21 补齐为接口）**：`GET /api/session` 在原有 `authenticated/user/role` 之外附 `permissions`：
- `business_auth`：Basic 是否启用、本次请求是否通过；
- `tokens`：`X-Prompt-Admin-Token` / `X-Rule-Admin-Token` 的 configured / supplied / valid（只回布尔，不回令牌值）；
- `actions[]`：17 个写动作，每项给 `method`/`path`/`requires[]`/`allowed`/`blocked_by`（`business_auth` /
  `token_not_configured` / `token_missing_or_invalid`）；
- `maintenance`：维护端入口与「业务端不代理升级包应用」的边界说明。
判定与路由守卫共用 `src/shared/token-auth.js` 的同一份实现——矩阵说 allowed 的路由一定不会回 403。
用例 `evidence/test/P003-T071/permission-matrix.test.js` 对**每条动作发一次真请求**：无令牌时 token 动作 403 / 普通动作非 403；
带齐令牌后全部非 403；未配置令牌时矩阵标 `token_not_configured` 且真调用 503。

**A18 业务端可见升级包（2026-11-21 实现）**：`GET /api/updates/packages` 只读列出可安装包元数据
（版本/标题/摘要/日期/更新日志/uploaded_at/applied/current/update_available），**不含二进制与提示词正文、不需要升级包密钥**。
元数据在入包（stage）与维护端读详情（detail）时落明文侧车 `<id>.meta.json`；业务进程只读侧车，
不代理维护端接口（AR-L0 §2 不变），应用仍只在维护端 18081 执行。用例覆盖「无密钥也能列」「无 CANARY/ciphertext」与「应用后 applied/current 翻真」。

**A19 身份可追溯**：两把静态令牌走 `actorOf({tokenKind})`，审计里标 `{kind:'token', id:'prompt-admin'|'rule-admin'}`；
每次 denied 也留 `result:'denied'`（既有行为不变）。
