## 4. A5 评估：行号锚点该不该换成函数名 + 稳定引用

**数据**：513 条锚点里 213 条漂了（41.5%），其中 74 条是「同一段代码被前面插了行」的纯平移，139 条是「那一行已经不是文档说的东西」。
本页历史上已经为这件事写过三次免责声明（「行号基准是 a16e0d5」「读的时候按函数名对齐」「全页重排留给文档卡」）——声明没拦住漂移，因为锚点是**位置**不是**身份**。

**结论：换，但要分层换，不要一刀切换。**

| 层 | 用什么 | 为什么 |
| --- | --- | --- |
| 契约/行为承诺（§8 导出表、§10 `R-TRIAGE-xx`） | **符号 + 可 grep 的签名**为主：`` `TriageMonitor#_acceptSyslog()` ``、`` `summary().paused` ``、`` `writeSyslogResult(caseInfo, result)` ``，行号只作附注 | 这几条是测试回指的目标（`// covers:` 靠 `R-TRIAGE-xx` 编号），身份比位置重要；符号改名时 grep 会立刻挂掉，而位置一动就悄悄错了 |
| 关键路径叙述（§3–§7 正文） | **函数名 + 一句「做什么」**，行号用「本页重取时」的口径统一挂在段尾，不再句中逐句点行 | 句子里散着几十个 `:行号` 时，任何一次改动都让整段失效；集中到段尾后，重取是「段尾那几行」的事 |
| 字段/取值表（§9、§8 参数表） | 保留行号，但**锚到声明处 + 使用处各一处**，并把「行号基准」那一行写进表头 | 这类锚点本来就是「这字段哪来的」，声明处比使用处稳 |
| 仅作示例的输出块（`grep` 期望输出） | 换成**命令 + 由命令生成**（本页 §1 已经这么写，但期望输出是手抄的） | 手抄的输出一定会烂；生成式可以用一条命令重新验 |

**代价**：一次性改写约 500 处、审一遍约半天；换来的是下次改代码时「锚点对不对」能用一条命令核、且核的是身份不是位置。
本卡已经把这套核账工具做出来了（`anchor-audit.mjs`），换符号锚点时同一套表结构照样能用（`new` 换成符号名即可）。
建议单独派一张卡做「§8 / §10 换符号锚点 + §3–§7 行号集中到段尾」，本卡只做评估不做改写（A5 口径）。
