**2026-11-21 补做**：
- **多结论分支**：`conclusions` 数组（additive）。主结论仍是 `verdict`，模型给 `conclusions` 时数组第一项是主结论的紧凑视图、其余是完整分支；
  每条分支各自过 `verifyClaims` + `danglingCitations`，分支缺失汇总进顶层 `validation.dangling_citations`（前缀 `conclusions[i]`）。
  单条结论/旧记录不落该字段，`verdictBranches()` 统一返回长度 1；记录体积不因新功能膨胀（T051 的 20k 字上界用例仍绿）。
- **复核提示词独立成段**：新增 `prompts/review.md` 与 core 段 `review`（`PromptStore.coreFiles/coreNames`），
  复核轮用 `review` 段 + SOP，不再复用 triage 段；复核仍走独立 `reviewModel` 实例。
  老升级包（21 段）允许缺 `review`：`UpdateStore.validate`/`PromptStore.install` 都按「可选章节」处理，应用时沿用当前正文，
