### A2 同一类不再这一处 400、那一处 502 —— 满足

判定下沉到一处（`failureKindOf`，`server.js:370-374`）：显式 `failure` 标记 → `4xx status` → 调用点缺省类；5xx 不给调用点覆盖。实测同类同码（同一套单测）：

```

✔ A2 调用方那一类保留 4xx 里的既有档位，code 一律 caller_error   （400 / 404×2 / 405 / 410 逐条）
✔ A1 code 与状态码固定对照…                              （上游：/api/alerts 与 /api/status 都 502；本程序：wiki 页读、规则配置写、研判开关都 500）
✔ A2 未被路由接住的异常也按四类走：读正文错了是 400，本地存储意外是 500（不再一律 502）
```

改掉的三处「同类异码」（`docs/modules/http-api.md` §8.3 对照表里有全表）：

### A3 上游失败带上游的码或一句摘要；本程序意外不把堆栈回给调用方 —— 满足

