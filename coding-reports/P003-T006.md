## 三、验收逐条

### A1 白板列表接 count / offset 并回 total（B13）

- 代码：`server.js:237-244`、`trace-board.js:173-179`
- 证据：`paging-session.test.js` 三条用例全绿——
  - `HTTP 白板列表把 count / offset 交给服务层并回 total`：`?count=5&offset=10` → 服务层收到 `{count:5,offset:10}`，空参数 → `{count:20,offset:0}`
  - `HTTP 白板列表分页参数不合法回 400，且不调服务层`：`count=0|51|abc|20.5`、`offset=-1|1.5` 全 400「分页参数无效」，且服务层调用次数 0
  - `HTTP 白板列表没配白板服务时 503 先于分页校验`：`?count=0` → 503
  - `白板 page 回本页摘要与切页前总数，按更新时间倒序` / `白板 page 在没有目录、坏文件时不抛，只数有效白板`：`total` 恒为切页前有效白板数

### A2 知识库列表接 count / offset 并回 total（B14）

- 代码：`server.js:322-334`
- 证据：`paging-session.test.js` 四条用例全绿——
  - 不带 `count` → 4 条全回、`total:4`（兼容）
  - `?count=2&offset=1` → `['GEN-2','GEN-3']`、`total:4`；`?offset=3` → `['GEN-4']`；越界 `?count=10&offset=9` → `pages:[]`、`total:4`
  - `?q=gen&count=10&offset=5`（60 页全匹配）→ `total:50`（`q` 的 50 条上限）、页内 10 条从 `GEN-6` 起
  - `count=0|51|abc|2.5`、`offset=-1|abc` → 400「分页参数无效」

### A3 GET /api/session 回 user 与 role（B17）

- 代码：`server.js:208-214`；群主定：`role` 固定 `operator`，未配密码时 `user`/`role` 为 `null`
- 证据：`paging-session.test.js` 三条用例 + 实跑探针（`/tmp/session-probe.mjs`，未入树）：

```
B1 无凭据 | 401 | 需要登录后访问
B2 错密码 | 401 | 需要登录后访问
B3 正确凭据 | 200 | {"authenticated":true,"user":"ops","role":"operator"}
B4 非 Basic 前缀 | 401 | 需要登录后访问
B5 空密码放行 | 200 | {"authenticated":true,"user":null,"role":null}
```

  单测另覆盖「配了密码没配账号名 → `user` 落回 `admin`」。
