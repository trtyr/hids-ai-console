# P003-T064 交付报告 · 聚合统计与导出（T064 + T065）

**新增路由**（均在 Basic 闸门后、未进 openapi 的 JsonObject 兜底——schema 留给 T067 批次补）：

- `GET /api/stats/trend?bucket=hour|day&days=1-90`：按 created_at 分桶计数，来自 monitor.records 全量（绕过 /api/alerts 的 500 条扫描上限）。
- `GET /api/stats/top?dimension=host_ip|source_ip|event_type|user&limit=1-100`：TOP-N 降序。
- `GET /api/stats/summary`：误报率（分母=有结论的 done 案件、分子=false_positive）+ MTTR（created_at→saved_at 中位数，无结论案件不计）。
- `GET /api/export/{dataset}?format=csv|json`（dataset=alerts|cases|logs|boards）：CSV 带 UTF-8 BOM + Content-Disposition 附件、统一并集表头；只读不写；越权 dataset/format 400 caller_error。

**验收对账**：trend/top/summary 各有 fixture 用例（含空数据/单点/跨桶边界）；export 验证 BOM 原始字节（res.text() 会剥 BOM，用 arrayBuffer 验）、CSV 行数 = 表头+数据行、非法参数 400、JSON 是数组。**MTTR 口径**在代码注释与测试里写明：无结论的案件不入分子也不入 MTTR 样本。测试 5 条全绿（evidence/test/P003-T064/stats.test.js）。
