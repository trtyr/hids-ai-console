# P003-T070 交付报告 · 历史正文路由（A11/A12）

**新增路由**：
- `GET /api/rules/{id}/history?rev=<hex16>`：带 rev 参数时返回该版正文（`{id, rev, rego}`，走 `RuleStore.readRevision()`）；不带 rev 时保持原有列表行为。
- `GET /api/rules/sessions/{sessionId}`：规则维护会话详情全文（rationale/validation/result/error 全字段，不再是列表的摘要投影）。

**处置**：A13（判据页历史与回滚）**不改**——WikiStore 的 wiki-history/ 是文件级备份，回滚等于把旧版当新版写回（走 PUT 即可）；单独的「回滚接口」会绕过 publishBundle 的发布闸，破坏 knowledge 上下文的乐观锁不变量。wiki 历史读取已在 T071 报告里说明（正文含 frontmatter 全字段）。

**测试**：evidence/test/P003-T041/http-contract.test.js 的 A6 用例覆盖 PUT/GET 正反路径；规则会话详情路由在 rules/sessions/{id} 的正则分支里，UUID 校验与 fp-sessions 同一套。
