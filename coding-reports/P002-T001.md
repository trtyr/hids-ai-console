### 三个实现决定（都记在这里，不改契约）

1. **单页 + hash 路由**，不是设计稿那样七个 HTML。原因：Basic 凭据只在内存，多页跳转会整页重载 → 每换一次页面就要重新登录。
   D002 写明「实现形态由写者选」。
2. **`web/serve.js` 反代 `/api`**。原因：`server.js` 没有静态文件路由，也没有 CORS 头（`server.js:53-56`），跨端口直连会被浏览器拦。
   反代只为把页面与 `/api` 放到同源，不改后端、不加 CORS 头。
3. **单测 DOM 用 jsdom**（`web/package.json` 的 devDependency，装在 `web/node_modules`，`.gitignore` 已覆盖 `node_modules/`）。
   原因：`testing.md` 要求按 role/name 查询，纯字符串断言测不出可访问性；仓里没有前端测试框架可复用，这是最小的可行选择。

## 三、验收逐条

### A1：`web/` 下能打开登录页；提交走本仓会话接口，不写死演示账号

- 能打开：`node web/serve.js` → `http://127.0.0.1:13300/` 200，登录页渲染（accessibility 快照见第四节）。
- 提交走本仓接口：浏览器里登录一次，`performance.getEntriesByType('resource')` 里与 `/api/` 相关的**只有** `http://127.0.0.1:13300/api/session`。
  adapter 全文件只有一处 `fetchImpl('${baseUrl}/api/session')`（`web/src/session.js:44`）。
- 不写死演示账号：`grep -rn "hids-2026|DEMO|demo" web/src web/index.html` 只命中 1 行，是 `web/src/views/login.js:3` 的注释（说明「稿里的演示账号整段没有搬」），**没有任何可执行代码或页面文本**；`web/README.md` 记了同一口径。
- 单测把「请求形状」钉住：`web/test/session.test.js:22-30` 断言 URL `/api/session` + `Authorization: Basic <base64>`。
- 承载这条验收的静态服务本身扛打：`curl 'http://127.0.0.1:13300/%zz'` → **400**，紧接着 `curl /` → **200**（服务没被打崩）；`web/test/serve.test.js:60-69` 是这条的回归用例。

### A2：登录成功进入总览壳；401 显示错误；侧栏能去五页（可先空着）

- 登录成功 → 壳：实测（第五节）点「登录」后 URL 变 `#/overview`，侧栏 + 顶栏 + 占位出现；标题「总览」。
- 401 → 错误：实测横幅 `role=alert` 可见，文本「登录失败 账号或密码不正确。」，密码被清空，焦点回密码框，按钮恢复可用。
- 侧栏五页：实测逐项点击 → `#/overview` / `#/alerts` / `#/trace` / `#/rules` / `#/knowledge`，每次顶栏标题、`aria-current="page"`、占位标题同步（只有 1 个 `aria-current`）。
- 五个页面先空着：每页占位文案「<页面名>尚未接入」，不画假数据（`web/test/shell.test.js:59-69` 断言占位里没有 button / table / input）。

### A3：会话接口没返回账号名、角色 → 不显示，不编

- 接口事实：200 体只有 `authenticated`（`openapi.yaml:36-40`），实现 `server.js:134` 也只回这一个字段。
- 界面事实：壳里**没有任何账号名/角色节点**（`.who` / `.avatar` 连样式都没留），侧栏可见文本实测为
  `HIDS AI 研判平台 总览 告警 深度溯源 规则 知识库 退出登录`——没有身份字样。
- 单测把负向断言钉住：`web/test/shell.test.js:46-55`（侧栏文本不匹配 `账号|角色|值守|admin`，且没有 `.avatar/.who`）；
  `web/test/session.test.js:78-83`（会话对象只有 `authenticated` 一个键，不臆造字段）。
