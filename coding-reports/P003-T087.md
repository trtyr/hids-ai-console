# P003-T087 交付报告 · 知识库 Agent 强化

**落地**：
1. **判据页版本历史 / 取版 / 回滚** ✅：`WikiStore` 新增 `history(pagePath?)` / `readRevision(id, rev)` / `rollbackTo(pagePath, rev, {note})`。历史本来就在 `wiki-history/`（形制 `<id>-<rev>.md`），本卡补的是读与回滚的路由：`GET /api/wiki/pages-history`、`GET /api/wiki/revisions`、`POST /api/wiki/rollback`。回滚走 `update()` 同一道闸（乐观锁 + 旧版备份 + log.md 记账），所以回滚本身也进历史。
2. **判据引用图** ✅：`GET /api/wiki/reference-graph` 返回 `{nodes, edges[{from,to,kind}], inbound}`；边分 `refs`（判据引判据）与 `evidence`（判据引证据页），`inbound` 是反向索引。
3. **研判闭环** ✅：`GET /api/wiki/usage?id=HP-01` 从落盘研判记录的 `trace`（wiki 动作）与 `verdict.wiki.consulted` 反查使用过的研判、结论分布与最近 20 条。
4. **PUT /api/wiki/pages 契约** ✅（T067 已落）。

**未做并说明**：
- **发布审核流三态显式化**：`WikiWorkbench` 的状态机已是 `collecting → ready_for_review → published`（加 `needs_non_wiki_fix`），审核人/结论/有效期结构化在 `record.audit`（reviewer/note/at/evidence_path/replay_status/replay_count）。草稿态 `draft` 在页面 frontmatter 里（`status:`）。**我认为现状已满足「三态显式化 + 审核信息结构化」**，不再加一层状态字段（会与 frontmatter 的 status 形成两份真源）。
