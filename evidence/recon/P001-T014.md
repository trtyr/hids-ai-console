


### C4 权限错误与目录不存在

## 四、没查到的

1. **记录保留多久、谁负责清理**：代码里没有删除接口（E13），也没有保留期配置项；保留策略属于仓外部署决定，仓内无处可查。
2. **本模块曾经出过什么故障**：文件在仓内只有一次提交（C6），没有更早的修改记录，「历史上怎么坏过」在仓内无从查证。
3. **告警 ID 的完整取值范围**：本模块只校验 `alert_id` 非空（E4），格式约束在 HTTP 路由层（E16）；两种模式各自接受哪些 ID 形态由 `eventTypes` 表决定，不在本模块内。
