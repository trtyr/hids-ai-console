## 1. 功能理解

后端现在只有 4 处零散的 `console.log/error`（`server.js:892,899,900,902`、`syslog-input.js:111,112`），HTTP 请求、研判入队/完成/失败、牧云调用失败、误报维护结果都没有日志可查——出事只能翻 `.data/triage-monitor.json`。
本卡要建**一个日志落点**（一行一条 JSON 到 stdout，带 `time` / `level` / `event`，告警相关的带 `alert_id`），把这五类事件全覆盖，且日志里不出现 Authorization / Cookie / API Token，不新增依赖。

- 被碰到的既有行为：启动段那 4 行中文 stdout 文案没了（`docs/architecture.md:470` 原样引用过），本卡一并改文档。
