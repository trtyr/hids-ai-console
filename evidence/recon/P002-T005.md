| 项 | 值 | 出处 |
| --- | --- | --- |
| operation 1 | `GET /api/trace/boards`（`listTraceBoards`）→ `{ boards: [...] }` | `openapi.yaml:313-329`；`server.js:157-160`；`trace-board.js:158-171` |
| operation 2 | `POST /api/trace/boards`（`startTraceBoard`），正文 `{ target }`，202 → `TraceBoard` | `openapi.yaml:330-351`；`server.js:161-168`；`trace-board.js:198-222` |
| operation 3 | `GET /api/trace/boards/{target}`（`getTraceBoard`），path 里的冒号要编码 | `openapi.yaml:352-370`；`server.js:169-177`；`trace-board.js:173-190` |
| 错误码 | 400 目标无效；404 尚无白板；422 该告警没有可用资产/来源 IP（仅 POST）；503 模型或 MCP 未配置；502 启动失败 | `server.js:161-177`；`trace-board.js:202,212,218` |
| 错误体 | `{ "error": "<中文说明>" }` | `server.js:57` |
| 鉴权 | HTTP Basic，每请求都校验 | `server.js:58-68`、`:130` |

**元素真实字段**（`trace-board.js`）：

- `board`：`id`、`alert_id`（IP 溯源为 null）、`run_id`、`title`、`seed`、`status`（`running|done|failed|interrupted`）、
  `window{since,until,hours}`、`created_at`、`updated_at`、`nodes[]`、`edges[]`、`activity[]`、`summary`、`gaps[]`、
  `investigations`、`model`、`origin_evidence`、`focus`。
- 列表项只有五个键：`id`、`title`、`status`、`created_at`、`updated_at`（`trace-board.js:167`）——**没有 nodes/edges 计数、没有 summary**。
- `node`：`id`、`label`、`address`、`kind`（`asset|external_ip`）、`status`（`pending|done`）、`why`、
  `profile{}`、`findings[]`、`finding_count`、`discovered_from[]`，调查过的还有 `touched_hosts`、`investigated_at`。
- `edge`：`from`、`to`（都是 node.id）、`rel`、`why`、`strength`（0..1）、`by`（`program|ai`）、`at`、`citations[]`。
- `activity` 元素：`at`（ISO）、`kind`（`seed|tool|tool_error|investigate|link|conclude|look|thinking|model_error|error`）、
  `title`、`detail`，`investigate` 带 `node`（node.id），`link` 带 `edge`（下标）。
- **没有 x/y 坐标字段**：布局是展示层（`trace-notes.md` §5 已写明力导向由前端算）。
