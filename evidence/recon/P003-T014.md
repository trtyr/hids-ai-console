## 1. 功能理解

深度溯源从「一条告警」开始：已有白板直接返回，没有就从这条告警往回走。
列表给运维挑一条看（类型 / 主机 / 告警时间 / 状态 / 链长 / 断点 / 更新时间，可筛可分页），
详情是一条往回的链（`hops` / `links` / `gaps` / `discovery`，线由更晚指向更早）。
告警分析已经取到的证据（syslog 形态的分析记录里留着原始报文）直接引用，不再为同一份查牧云。
