## 四、指纹复算

```
$ node -e "
import('node:crypto').then(async ({createHash}) => {
  const {PromptStore} = await import('./prompt-store.js');
  const sha16 = o => createHash('sha256').update(JSON.stringify(o)).digest('hex').slice(0,16);
  const active = await new PromptStore().load();
  const snap = await new PromptStore().snapshot();
  const composite = {prompts:active.prompts, scenarios:active.scenarios, sop:active.sop, release:null};
  const wikiOnly = Object.fromEntries(Object.entries(active.sop).filter(([id]) => !['common','command_whitelist'].includes(id)));
  console.log('revision 复算', sha16(composite), '上报', active.revision, sha16(composite)===active.revision);
  console.log('knowledge_revision 复算', sha16(wikiOnly), '上报', snap.knowledge_revision, sha16(wikiOnly)===snap.knowledge_revision);
  console.log('knowledge_revision 覆盖条数', Object.keys(wikiOnly).length);
});
```

## 七、装配失败面

```
$ mkdir -p /tmp/p001t012-emptywiki && HIDS_WIKI_DIR=/tmp/p001t012-emptywiki node -e "
import('./prompt-store.js').then(async m => {
  try { await new m.PromptStore().load(); } catch (e) { console.log('load =>', e.code, e.path); }
});"
load => ENOENT /tmp/p001t012-emptywiki/webshell/WS-13.md

$ node -e "const path=require('node:path'); try { path.join('/x', undefined); } catch (e) { console.log(e.constructor.name, e.message); }"
TypeError The "path" argument must be of type string. Received undefined
```

`HIDS_WIKI_DIR` 指向空目录时，`load()` 在读判据页这一步抛 ENOENT（`prompt-store.js:43`），
不会退回仓内 `wiki/`。`wikiSop` 映射表里没有的卡片 id 会让 `path.join` 收到 `undefined`
（`prompt-store.js:43`），按上式会抛 TypeError——这是代码推出的后果，未在真实数据上触发。

```
$ node -e "import('./prompt-store.js').then(async m => {
  process.env.HIDS_WIKI_DIR = '/tmp/p001t012-emptywiki';
  const s = new m.PromptStore();
  try { await s.load(); console.log('import 之后再改环境变量：load 仍成功'); } catch (e) { console.log('load 失败', e.code); }
});"
import 之后再改环境变量：load 仍成功
```

两个环境变量在 import 时读一次（`prompt-store.js:9`、`prompt-store.js:17`），进程内再改不生效。
