## 5. A3 的反面对照：空数据根（不先种子）数出来的不是 23

旧跑法（空数据根直接 trace）在本机数出 **213 次** openat / 201 个唯一路径，断言 23 必红——
这正是把 A3 改成「固定数据根 → 先不 trace 跑一次种子 → 覆盖文件写 `{}` → 再 trace」的原因。

```bash
$ rm -rf /tmp/t057-a3-old && mkdir -p /tmp/t057-a3-old/data
$ HIDS_DATA_DIR=/tmp/t057-a3-old/data HIDS_PROMPT_STORE_FILE=/tmp/t057-a3-old/prompt-overrides.json \
    strace -f -e trace=openat -o /tmp/t057-a3-old/trace.txt \
    node -e "import('./prompt-store.js').then(async m=>{const a=await new m.PromptStore().load();console.log('rev:',a.revision)})"
rev: 065221c4b66f7660
$ grep -oE '"[^"]*(/prompts/[^"]*\.(md|json)|/data/wiki/[^"]*\.md|prompt-overrides\.json)"' /tmp/t057-a3-old/trace.txt | wc -l
213
$ grep -oE '"[^"]*(/prompts/[^"]*\.(md|json)|/data/wiki/[^"]*\.md|prompt-overrides\.json)"' /tmp/t057-a3-old/trace.txt | sort -u | wc -l
201
```

种子后的固定数据根（脚本里的做法）数出 23 总 openat / 23 唯一 / 0 ENOENT / 23 条全是 `O_RDONLY`，与页面 §10 的 7+1+14+1 逐项对上。
