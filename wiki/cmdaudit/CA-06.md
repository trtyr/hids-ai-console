# CA-06 · syslog 和 API 各有什么

## syslog 和 API 各有什么

### syslog 侧（单条命令级，19 个字段）

| 字段 | 是什么 |
| --- | --- |
| `session_id` | **会话 id —— 这一类最重要的字段** |
| `process_command_line` | 这一条命令 |
| `process_id` / `process_tree` | 进程链 |
| `user_id` / `user_name` / `user_gid` / `user_gname` | 谁 |
| `env` | 环境变量（**JSON 字符串**） |
| `event_start_time` / `event_end_time` / `event_create_time` | 时间 |
| `file_path` | 相关文件 |

### API 侧（会话级，8 个字段）

| API 字段 | 等价于 |
| --- | --- |
| `session_id` | 同 syslog |
| `shell_started_at` | 会话开始 |
| `shell_duration` | **shell 存活多久**（不是「跑了多久命令」） |
| `event_count` | 这个会话里几条命令 |
| **`suspicious_event_count`** | **其中几条被判可疑** |
| `uname` | 谁 |

### 两边的粒度不一样（关键）

```text
syslog  一条 = 一条命令
API     一条 = 一次会话（含统计）
```

**所以 API 是「目录」，syslog 是「正文」。**
API 告诉你「这个会话有 3 条命令、1 条可疑」，
syslog 才能告诉你「那 3 条具体是什么」。

### 关联方式

`session_id` 是**直接的主键**，不需要按时间窗猜 ——
这是 12 类里唯一一个能精确关联的。

> ⚠️ 但 demo 里 syslog 的 `session_id` 和 API 的 `session_id`
> **是同一套格式**（UUID），所以能对得上。真实环境要验证这一点。
