# CA-05 · 什么命令形态该被注意到

## 什么命令形态该被注意到

**这一类看到的命令最多，但绝大多数是正常的。** 所以要有一份「该看一眼」的清单。

### 该注意的（按危险程度）

| 形态 | 例子 | 为什么 |
| --- | --- | --- |
| **下载后直接执行** | `curl ... \| bash`、`wget -O- ... \| sh` | 不看内容就跑 —— 最典型的投放方式 |
| **反弹特征** | `bash -i >& /dev/tcp/...`、`nc -e /bin/sh ...` | 见反弹 Shell 类（RS-03） |
| **加密/编码执行** | `base64 -d \| sh`、`python -c "exec(...)"` | 不想让人看懂 |
| **权限提升** | `chmod +s`、`find / -perm -4000`、`sudo -l` | 见本地提权类（LP-02/04） |
| **摸防御** | `ps aux \| grep -E 'clamb\|defender'`、`systemctl stop auditd` | 反侦察（SC-08） |
| **清痕迹** | `history -c`、`> ~/.bash_history`、`rm -rf /var/log/*` | |
| **横向** | `ssh other-host` / `scp ... @other-host` / `nmap` | 从这台去打别的机器 |

### 不该被注意的（占绝大多数）

| 形态 | 为什么正常 |
| --- | --- |
| `ls` `cd` `pwd` `cat` `less` `grep` `find`（不带 `-perm`） | 看文件 |
| `systemctl status` / `journalctl -u` | 查服务 |
| `apt` / `yum` / `docker ps` | 日常运维 |
| `vi` / `nano` / `vim` 编辑配置 | |
| `top` / `htop` / `df` / `free` | 看状态 |

**这一类的降噪价值就在这里**：90% 以上的会话是上面那张「不该注意」的表。
**判「误报」要快、要敢。**

> ⚠️ 但有一条例外：**自定义脚本**。
> `./backup.sh`、`/opt/xxx/run` 这类看不出内容的，
> 既不能判「正常」也不能判「可疑」 —— 归到存疑或者交给别的类。
