# CA-01 · 这一类是什么：不是告警，是会话流水

## 这一类的结构跟别的类**根本不同**

**别的类**：一条 alert = 一个可疑动作，问「这是不是攻击」。

**这一类**：一条记录 = **一次登录会话**，里面有好几条命令。

```text
id                      会话 id
session_id              会话唯一标识
shell_started_at        这个 shell 什么时候起来的
shell_duration          持续了多少秒
event_count             这个会话里跑了多少条命令
suspicious_event_count  **其中有多少条被判可疑**
uname                   谁
```

**它没有 `event_name` / `event_level` / `event_state`** ——
因为**它不是告警**，是「这台机器上这个人干了什么」的全量流水。

### demo 实测（16 个会话）

| 命令数 | 可疑数 | 时长 | 说明 |
| --- | --- | --- | --- |
| 26 | 0 | 842 秒 | 一次长会话，全是正常命令 |
| 1 | 0 | 583 秒 | 登上去敲一条就挂着 |
| 3 | **1** | 9 秒 | 短会话但有一条可疑 |
| 2 | **1** | 69 秒 | |

**注意第二行**：1 条命令、583 秒 —— 这说明 `shell_duration` 是
「shell 存活多久」，**不是「跑了多久的命令」**。

### 所以这一类要回答的问题

**不是「这条告警是不是攻击」**（它根本不是告警），而是：

**这次会话，值不值得人去看？**

- 26 条命令全是 `ls` / `cd` / `cat` → 运维在排查，不值得看
- 3 条命令里有 1 条可疑 → **值得看**，而且要看那一条是什么
- 1 条命令跑了 583 秒 → 可能是个挂着的 shell，也可能是长跑脚本
