# CA-08 · 命令记录判定路径

**要回答**：同一身份和会话里实际执行了什么，命令之间是否形成可验证的攻击链。命令记录本身首先是证据，不是独立处置对象。

1. **还原会话**：按会话 ID 优先；缺 ID 时核对账号、源、目标、时间和终端标识。保留命令原文、退出状态、执行用户和前后事件。
2. **标出需要复核的动作**：下载、执行、反弹通道、权限修改、凭据访问、清痕或防护变更分别标注；`curl`、`nc`、`find` 等工具名不能单独定性。下载与执行必须分开。
3. **查结果与授权**：核对落地文件、进程、网络连接及工单范围。`suspicious_event_count > 0` 是关联线索；`= 0` 只表示没有命中现有规则。
4. **结论**：有可信的未授权攻击链或后果 → 真实威胁；整段会话经核实属于授权操作且无相反证据 → 误报；会话不完整、命令缺参或结果未知 → 存疑。

**限制**：牧云当前事件类型里未必有独立“命令记录”事件，需从可疑操作详情或会话审计获得材料。ATT&CK [T1059、T1105](../_evidence/mitre-original-2026-11-09.md)用于描述行为，不能代替本次执行证据。

**SOP 对照**：`sops/cmdaudit/SOP.md` 第二至四章，以会话为判定粒度。
