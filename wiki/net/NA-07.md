# NA-07 · syslog 和 API 各有什么

## syslog 和 API 各有什么

### syslog（22 个字段，**唯一自带归属地的类**）

| 字段 | 有用吗 |
| --- | --- |
| `event_type` | 哪一类网络行为（demo 全是 `dns`） |
| `process_name` / `process_path` / `process_command_line` | **谁发的（判据核心）** |
| **`ip_owner` / `ip_isp`** | **归属机构 / 运营商** |
| **`ip_country_code` / `ip_province_code` / `ip_city_code`** | **归属地** |
| ⚠️ **没有目标 IP / 域名** | **要去 API 拿** |

### API（`NetworkAuditEventService.GetEventList`）

| 字段 | 是什么 |
| --- | --- |
| **`target`** | **目标** —— 域名（dns）或 IP:port |
| `type` | 类型（`dns` 等） |
| `owner` / `isp` / `country_code` / `province_code` / `city_code` | 归属地 |
| `repair` | 牧云认为的状态 |

> ⚠️ **`target` 有时是 UUID 而不是域名**（demo 里 50 条）。
> 那可能是「域名被哈希了」或者「拿不到真名」——
> 这种情况**判不了具体目标**，只能按「有外连行为」处理。

### 两条硬规矩

1. **`target` 拿不到就判不了** —— 这一类的第一判据是「连到哪」。
2. **归属地字段在 demo 里全是空的** —— 别假设它一定有值。
