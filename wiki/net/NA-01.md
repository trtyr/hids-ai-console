# NA-01 · 这一类在说什么

## 一条网络异常告警，说的是什么

**这台机器上有个进程发起了它觉得不该有的网络行为。**

`event_type` 会告诉你是哪一类。demo 实测的前 500 条**全是 `dns`**。

### syslog 有一个特殊的点（12 类里独一份）

**它自带 IP 归属地**：`ip_owner` / `ip_isp` / `ip_country_code` /
`ip_province_code` / `ip_city_code`。

别的类要查地理信息得走 API 或情报缓存，**这一类 syslog 直接给了。**

### 但 syslog **没有目标 IP**

字段里有归属地、有进程、有命令行，**就是没有「连到哪个 IP/域名」**。

那个在 API 的 `target` 里。

### 要回答的问题

**不是「有没有网络行为」** —— 网络行为是常态。

**是：这个行为，是不是一个「不该出现在这台机器上」的通道？**
