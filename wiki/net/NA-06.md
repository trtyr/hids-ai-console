# NA-06 · 非 DNS 的网络异常怎么判

## 非 DNS 的网络异常怎么判

demo 里 500 条全是 `dns`，但字段里 `event_type` 是开放的，
真实环境可能有别的类型（「异常IP外连」等）。

**判法和 DNS 一样，还是那三问：**

| 问 | DNS | 非 DNS |
| --- | --- | --- |
| **连到哪** | 域名（API 的 `target`） | IP:端口（API 的 `target`） |
| **谁发的** | 进程 | 进程 |
| **目标对不对劲** | 回连测试域名 / 随机子域名 | **归属地 + 端口 + 是否已知 C2** |

### 非 DNS 时，syslog 的归属地字段就派上用场了

**这是这一类独有的优势** —— 别的类要查 IP 情报，这一类 syslog 直接给了：

| 字段 | 怎么用 |
| --- | --- |
| `ip_country_code` | 国家不在「已知业务国家」里 → 加重 |
| `ip_owner` / `ip_isp` | **「阿里云」和「某不知名 VPS 商」分量完全不同** |
| `ip_province_code` / `ip_city_code` | 国内业务只连国内 → 境外要问 |

> ⚠️ 但 demo 的数据里这些字段**全是空的**（`country_code` 120 条全空）。
> 所以这条判据**在 demo 上验不了**，只能写进判据等真实环境。
