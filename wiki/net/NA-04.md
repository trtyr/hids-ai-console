# NA-04 · `dnslog` 这类回连测试服务：出现即高危

## `dnslog` 这类回连测试服务

**这一类域名有一个共同特征：它们存在的意义就是「被攻击者用」。**

| 域名 | 用途 |
| --- | --- |
| `dnslog.cn` | DNS 回连测试（盲注、命令执行确认） |
| `ceye.io` | 同上 |
| `burpcollaborator.net` | Burp 的带外测试 |
| `interact.sh` / `oast.pro` / `oast.fun` | ProjectDiscovery 的 OAST |
| `requestbin.net` | HTTP 回连 |

**正常业务不会访问这些域名。一个都没有。**

### 所以这条判据是「准硬证据」

| 情况 | 判 |
| --- | --- |
| 解析到 `dnslog.cn` / `ceye.io` 这类域名 | **真实威胁**（除非能证明是安全团队在测） |
| 子域名带 UUID / 长随机串，且是这些域名 | **真实威胁**（在带数据） |
| 普通域名 + 普通进程 | 往误报方向看 |

> ⚠️ **注意「除非是安全团队在测」这个前提。**
> demo 里那 450 条 `xxx.dnslog.cn` 就是测试产生的 ——
> 所以「这台机器是不是测试机」这个条件仍然要问（和恶意文件类的 MA-06 同一个道理）。
