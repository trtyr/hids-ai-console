# BF-03 · 凭证攻击的三种形态：怎么从字段上分开

## 凭证攻击的三种形态（MITRE T1110）

| 形态 | 长什么样 | 在数据里怎么认 |
| --- | --- | --- |
| **Password Guessing**（T1110.001） | 一个来源 → 一个账号 → 试很多密码 | `failure_count` 高、来源 IP 少 |
| **Password Spraying**（T1110.003） | 一个来源 → **很多账号** → 每个试几个 | 来源 IP 稳定、但**账号面广** |
| **Credential Stuffing**（T1110.004） | 拿泄露的账密批量试 | 来源 IP **很多**、失败次数每个都不多 |

MITRE 的区分标准是「**广度在哪**」：

- 广度在**密码**上 → Guessing
- 广度在**账号**上 → Spraying
- 广度在**来源**上 → Stuffing

### 我们能分开到什么程度

**只有 `source_ip` + `failure_count` + 时间窗，分不干净。**
账号维度在 `auth_service` 里有服务名，但**没有登录账号**。

所以：**能判「这是不是攻击」，分不清「是哪一种」—— 分不清就写分不清。**

> ⚠️ 不要因为「看起来像 Spraying」就判得更重。形态不同不改变结论，
> 只改变处置建议（Spraying 要查更多账号）。
