# BF-05 · 来源是内网时，噪音这个解释不成立

## 来源是内网时，「背景噪音」这个解释不成立

Elastic 说 SSH 爆破会产生大量噪音，前提是**对面是互联网**：
攻击者满世界扫，扫到谁算谁。

**内网不一样。**

一台内网机器在试另一台内网机器的密码，只有三种可能：

| 可能 | 性质 |
| --- | --- |
| 运维在用脚本批量改密码 / 巡检 | 良性，但**要有登记** |
| 某台机器上有自动化工具配错了 | 良性，但要修 |
| **某台机器已经沦陷，正在横向** | **极恶性** |

**这三种在日志里长得一模一样。**

所以：**来源在内网时，判「误报」必须有人工确认过**，
不能由 Agent 单方面认定是噪音。

> 这条和蜜罐类的 HP-01 是同一个道理：
> 「背景噪音」这个词自带「互联网」这个前提，别把前提丢了。
