# AL-05 · 归属地漂移是**加重项**，不是定罪项

**这个 IP 的归属地，跟这台机器历史上见过的来源不一样。**

比如一台北京的数据库，平时登录都来自北京，突然来一个瑞典的 IP。

## ⚠️ 但归属地会骗人

Microsoft 的 Impossible Travel 文档自己写了这条 caveat：

> 也可能是用户**真实位置被 VPN 掩盖**。

运维挂着公司 VPN 从海外出差，出口就在海外。**这种情况判威胁就是误报。**

**判据**：

| 情形 | 怎么算 |
| --- | --- |
| 归属地在**已知来源集合**内 | 弱良性信号 |
| 归属地**漂移** | 弱可疑信号，**加重**，不单独定罪 |

**IP 归属地从哪来**：推送组件的 IP 情报缓存 —— 第一次见到这个 IP 查一次，
之后一直用缓存。查不到就标「未知」，**不许猜**。
