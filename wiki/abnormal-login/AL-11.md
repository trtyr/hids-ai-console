# AL-11 · 异常登录判定路径

**要回答**：本次登录是否成功，是否由获授权主体发起，登录后是否出现与该会话可关联的异常行为。

1. **取事实**：账号、来源 IP 与地理信息、目标资产、认证结果、认证方式、登录时间、可用的会话或登录后进程记录。对多地登录先校准时间、代理/VPN 出口与账号共享情况。
2. **先看后续动作**：同会话或可靠关联的来源、账号、主机上，若出现未授权命令、持久化、提权或外连，记录各阶段和引用；不能把同主机同时段的无关事件硬串成链。
3. **核对身份**：查运维出口、值班窗口、工单和使用人。只有来源匹配还不够；核对账号、目标、时间与操作范围。窗口外也不自动代表攻击。
4. **结论**：确认未授权使用或有可靠关联的后渗透行为 → 真实威胁；确认属于预期授权会话且无相反证据 → 误报；缺少会话、身份或授权核验 → 存疑并说明需找谁确认。

**限制**：所谓“不可能旅行”是强异常线索，代理、移动网络和共享账号都可能造成假象；需要核实会话与出口后才能定性。MITRE [T1078](../_evidence/mitre-original-2026-11-09.md)说明攻击者会利用有效账号，并不把成功登录定义为攻击。

**SOP 对照**：`sops/abnormal-login/SOP.md` 第三章的九步流程；其中原有“来源和窗口直接判误报”的路径需加入逐项授权核对。
