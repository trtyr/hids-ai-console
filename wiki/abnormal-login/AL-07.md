# AL-07 · 判定程序

**拿到一条异常登录告警，按顺序走，第一个命中的就是结论。**

## 第 0 步 · 有没有真实威胁的硬证据？

出现以下之一 → **真实威胁**，直接结束：

- **登录后有攻击行为**（300 秒内同主机出现提权 / 可疑命令 / WebShell / 反弹 Shell /
  恶意文件 / 网络异常）—— AL-06b
- **不可能旅行**（同账号 3600 秒内从两个不同国家登录）—— AL-06

**这两条都不需要看来源可不可信、时段正不正常。**

## 第 1 步 · 能给「误报」吗？

两条路径任一成立：

### 路径 A · 可信来源 + 正常时段

来源 IP 在**运维出口池**里，且登录时刻在**运维窗口**内。
→ 正常的人、在正常的时间、从正常的入口进来 → **误报**

### 路径 B · 可信来源 + 可疑时段 + 高频

来源 IP 在运维出口池里，时段在窗口外，但**同一来源 + 同一账号在窗口内高频重复**
（超过配置的阈值，默认 10 次）。
→ 这是运维的固定习惯（比如每天半夜跑备份）→ **误报**

> ⚠️ **路径 B 的三个条件缺一不可。**
> 来源可信但低频 → 不是习惯，是孤立的一次 → 不成立（见第 2 步）。

## 第 2 步 · 都不成立 → **存疑**

典型的不成立场景：

| 场景 | 为什么存疑 | 该问人什么 |
| --- | --- | --- |
| 来源不在出口池 | 不知道是谁 | 这个 IP 是谁的？ |
| 内网直连绕开堡垒机 | 绕过了唯一入口 | 这台机器上跑着什么自动化脚本吗？ |
| 可信来源 + 时段可疑 + 低频 | 来源对，但这次不寻常 | 昨晚那次登录是你吗？ |
| 归属地漂移 | 可能挂着 VPN | 这个人最近出差/用 VPN 吗？ |

**存疑必须写清「缺什么信息才能定」** —— 只写「存疑」两个字，运维没法干活。
