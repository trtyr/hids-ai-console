# AL-09 · 处置建议：五个固定动作

牧云自己给的建议是（原文）：

1. 联系主机管理员确认是否人为触发
2. 非人为则改密码 + 清理登录公钥
3. 排查同密码其他系统
4. 防火墙阻断登录 IP
5. **进一步入侵检测查该 IP 所有访问记录**

**第 5 步就是我们做的「登录后行为关联」（AL-06b）** —— 牧云自己都说了要看这个 IP 干了什么，
我们把它自动化了。

**判成真实威胁时，这五步直接给出去。判成存疑时，只给前两条（先确认是不是人）。**
