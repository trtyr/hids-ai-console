# RP-05 · 判定程序

## 判定程序

```text
第 0 步 · 这次拦截，攻击成功了吗？
        · `action` = `warn`（只记录没拦）
        **且** `jspAbsPath` 在**真正的 web 应用目录**里
        **且** 不是运维登记的测试目录
        三条全成立                              → 真实威胁
        ↓ 缺任一条

第 1 步 · 能不能判「测试 / 已知活动」？
        · `jspAbsPath` 在运维登记的测试/POC 目录里
        · **且** 这台机器是测试机
        两条全成立                              → 误报
        ↓ 缺任一条

第 2 步 · 存疑
        写清缺什么
```

### 为什么第 0 步要三条

- 只有 `warn`，但路径在 POC 目录 → **是测试**，不是攻击
- 只有路径在 web 目录，但 `action = block` → **被挡住了**，
  性质不同（虽然也要查，但不是「已经进去」）
- 两条都成立、但不是这台机器的正常业务 → 还是要看 `action`

### ⚠️ `block` 不能判误报

**RASP 拦住一次注入尝试，说明「有人正在打这台机器」。**

这不叫误报，这叫「防住了」。判据 RP-06 会讲这个区别。
