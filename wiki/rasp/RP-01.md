# RP-01 · 这一类在说什么

## 一类「防护软件自己报的」告警

**内存安全和内存后门不一样：它是 Java RASP（运行时应用自我保护）报的。**

RASP 挂在 JVM 里，**在应用执行到危险操作的那一刻拦下来**。

### demo 只有 2 条

```text
event_name    = jsp
level         = 2（low）
process_name  = java
origin_method = public boolean org.apache.jasper.compiler.Compiler.isOutDated(boolean)
rule_entries  = [{ "name": "检测 jsp 文件修改时间与其它文件的相似性",
                   "action": "warn", ... }]
```

### 它报的是什么

**`Compiler.isOutDated` 是 Tomcat 在「JSP 文件被改过、需要重新编译」时调的方法。**

RASP 挂在它上面，是在看：**「谁刚改了一个 JSP，然后立刻访问它？」**

这是**上传 WebShell 的经典动作**：

```text
1. 传一个 .jsp 上去          ← 文件修改时间变了
2. 立刻访问它                ← 触发 JSP 重新编译
3. Tomcat 调 isOutDated      ← RASP 就在这里看到
```

### 要回答的问题

**不是「RASP 报了什么」** —— 它报了。

**是：这次拦截，是「攻击被挡住了」还是「攻击已经成功了」？**

**关键在 `action` 字段：`warn` 说明 RASP 只记录了，没拦。**
