# RP-07 · syslog 和 API 各有什么

## syslog 和 API 各有什么

### ⚠️ syslog 格式未知

跟内存后门一样 —— **syslog 文档 2.0 的 16 个 MsgId 里没有这一类**。

### API（`MemorySecurityEventService.GetEventList`）

| 字段 | 是什么 |
| --- | --- |
| **`event_name`** | 策略名（demo 是 `jsp`） |
| `process_name` / `pid` | 哪个进程（demo 是 `java`） |
| **`origin_method`** | **被 hook 的 Java 方法**（如 `Compiler.isOutDated`） |
| **`rule_entries[]`** | **命中的规则**（含 `action` / `name` / `reason`） |
| `attack_time` | 攻击时间（毫秒时间戳） |
| `level` / `state` | 等级 / 状态 |

清单里还记着：`plugin_id`（如 `com.chaitin.rasd.002.hook.jsp.001`）、
`strategy_id`、`agent_event_id`、`source_id`、`config_id`、
`stack[]`（调用栈）、`event_args { className, cmdline, dir, envp }`
—— demo 这几条没返回全部。

### `origin_method` 是这一类的「判据锚点」

它告诉你 **RASP 挂在哪**：

| `origin_method` 含 | 在防什么 |
| --- | --- |
| `Compiler.isOutDated` | JSP 被改后重新编译（**上传 WebShell**） |
| `Runtime.exec` / `ProcessBuilder` | 命令执行 |
| `ClassLoader.defineClass` | 动态加载类（**内存马**） |
| `ObjectInputStream.readObject` | 反序列化 |

**看到 `defineClass` 那类，基本就是内存马了。**
