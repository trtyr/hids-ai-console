# RP-04 · `jspAbsPath` 是 web 目录还是测试目录

## `jspAbsPath` 是 web 目录还是测试目录

**路径决定一切**（跟 WebShell 类同一个逻辑）。

| 路径 | 判 |
| --- | --- |
| **`.../webapps/ROOT/` 这类真正的 web 应用目录** | **真实的 Web 应用** —— 认真看 |
| `.../POC-tool_*/test/...` 这类**运维登记的测试目录** | **测试样本** → 误报 |
| 家目录 / 临时目录下的 webapps | 可疑 —— 可能是自己搭的测试环境 |

### demo 是什么

```text
/root/POC-tool_linux_amd64/test/apache-tomcat-9.0.88/webapps/ROOT/add_servlet.jsp
```

**`/root/POC-tool_linux_amd64/test/` —— 这是长亭的 POC 测试工具目录。**

所以 demo 这 2 条**都是测试产生的**，不是真实攻击。

> ⚠️ **但要注意**：判成「测试目录」之后，**不能简单判误报**。
> 因为「有人在生产机上跑了 POC 工具」本身也是要看的 ——
> 只是它的严重性是「谁在跑」，不是「这台机器被攻破了」。
