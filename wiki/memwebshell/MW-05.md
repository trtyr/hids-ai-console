# MW-05 · 内存马和 WebShell 的关系

## 内存马和 WebShell 的关系

**内存马 = 不落地的 WebShell。**

| | 传统 WebShell | 内存马 |
| --- | --- | --- |
| 有没有文件 | 有（`.jsp` / `.php`） | **没有** |
| 磁盘能不能查到 | 能 | **查不到** |
| 重启后还在吗 | 在 | **不在**（Java） |
| 怎么发现 | 扫文件 | **扫进程内存** |

### 所以这两类要连起来看

如果一台机器同时出现：

- **WebShell 告警**（有人传了个 `.jsp`）
- **内存后门告警**（`java` 进程里有多出来的恶意类）

那很可能是**同一次攻击**：传了 WebShell → 用 WebShell 注了个内存马 → 删了 WebShell 文件。

**这时候 WebShell 那条可能已经被删了（判不出来），而内存这条还在。**
