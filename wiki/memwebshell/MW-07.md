# MW-07 · syslog 和 API 各有什么

## syslog 和 API 各有什么

### ⚠️ 先说最重要的一条：**syslog 格式未知**

`docs/syslog/syslog-format-2.0.txt` 的 16 个 MsgId 里
**没有内存两类**（全文搜「内存」零命中）。

所以**这一类的 syslog 长什么样，我们不知道**。
下面写的是 **API 侧**的字段（已探明）。

### API（`MemoryWebshellEventService.GetEventList`）

| 字段 | 是什么 |
| --- | --- |
| `event_name` | 人话：「发现进程 X 内存中存在恶意代码」 |
| **`process_name`** | **恶意代码藏在哪个进程里（第一判据）** |
| `pid` | 进程 id |
| **`class_name`** | **Java 内存马才有值** |
| `server_name` | 哪个 Web 容器 |
| `type` | 形态编号（demo 只见过 2） |
| `level` / `state` / `repair` | 等级 / 状态 |

还有 `detect_reason`（检测原因，如「在内存中检测到 rapid7/mettle」）、
`class_loader`、`container_hash_id`、`object_path`、`md5`、`sha256`、
`process_info { id, name, path, started_at, cmdline, cwd, env[], user }`
—— 清单里记着，但 demo 这一条没返回。

### 这意味着什么

**这一类的 SOP 现在是「半成品」**：
判据写好了，但「输入长什么样」只能等实测。
