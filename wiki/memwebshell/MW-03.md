# MW-03 · 进程名就是最强的线索

## 进程名就是最强的线索

这一类的字段里，**`process_name` 的信息量最大**：
它告诉你「恶意代码藏在哪个进程里」。

### 三档

| 进程名 | 判定 |
| --- | --- |
| **已知攻击工具**：`mettle*` / `meterpreter*` / `beacon*` / `csagent*` | **真实威胁** |
| **正常服务**：`java` / `tomcat` / `nginx` / `sshd` / `mysqld` | **内存马 —— 真实威胁** |
| **运维工具**：扫描器 / 测试程序 / 已登记的 POC 目录下的 | 往误报方向看 |

### 为什么「藏进正常服务」反而更严重

一个叫 `mettle_amd64.el` 的进程 —— **它本来就是个可疑文件**，
杀它、隔离它，事情就结束了。

**但藏在 `java`（Tomcat）里的内存马不一样**：

- 那个 `java` 进程是**业务正在用的**
- 你不能直接杀它
- 而且它可能是**通过一个 WebShell 传上来的** —— 说明 Web 应用已经被攻破了

> ⚠️ 所以这一类的处置**第一个问题不是「怎么删」，是「这个进程能不能停」**。
