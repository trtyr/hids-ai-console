# MW-01 · 这一类在说什么

## 一类没有文件可以看的告警

**这类攻击不落地文件。** 恶意代码直接在**内存里**执行 —— 磁盘上看不到。

牧云的做法是：**扫进程的内存空间，看里面有没有可疑代码。**

### demo 只有 1 条

```text
event_name   = 发现进程 mettle_amd64.el 内存中存在恶意代码
level        = 4（high）
type         = 2
pid          = 93660
process_name = mettle_amd64.el
class_name   = （空）
```

`mettle` 是 **Metasploit 的 meterpreter payload** —— 这个名字本身就是答案。
而且是牧云自己的 POC 文件（清单里记着 `rapid7/mettle`）。

### 要回答的问题

**不是「内存里有没有恶意代码」** —— 引擎已经说了有。

**是：这段代码在哪个进程里、那个进程是什么、它正在干什么？**

| 进程是什么 | 含义 |
| --- | --- |
| **已知攻击工具**（`mettle` / `meterpreter` / `cobaltstrike`） | 极恶性 |
| **被注入的正常服务**（`java` / `nginx` / `sshd`） | **内存马** —— 服务本身被控制了 |
| 运维自己的工具（扫描器 / 测试程序） | 可能是误报 |
