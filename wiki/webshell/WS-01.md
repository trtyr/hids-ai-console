# WS-01 · 这一类告警在说什么

**牧云报的是「这台机器上有文件，长得像 WebShell」。**

它报的是**一个文件**，不是一次攻击。至于这个文件：

- 是攻击者传上来的？
- 是运维自己的安全测试工具留下的？
- 是一个正常业务文件被误判了？

**这三种情况在告警里长得一模一样。** 判这一类的全部工作，就是分清这三种。

## 权威定义

CISA 的 ATT&CK 技术条目 T1505.003 原文：

> "Adversaries may backdoor web servers with web shells to establish persistent access
> to systems. A Web shell is a Web script that is placed on an **openly accessible
> web server** to allow an adversary to access the Web server as a gateway into a network."

NSA/CISA 联合发布的《Detect and Prevent Web Shell Malware》(2020-04-22)：

> "Web shell malware is software deployed by a hacker, usually on a victim's web server.
> It can be used to **execute arbitrary system commands**, which are commonly sent over
> HTTP or HTTPS."

澳大利亚 ACSC 的《Web Shells – Threat Awareness and Guidance》：

> "A web shell is a script that can be uploaded to a web server to enable
> **remote administration** of the machine. Infected web servers can either be
> internet-facing or internal to the network, where the web shell is used to
> **pivot further to internal hosts**."

**三份资料说的是同一件事**：WebShell 是**放在能被 web 访问到的位置、用来执行命令的脚本**。
