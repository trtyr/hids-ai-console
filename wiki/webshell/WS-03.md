# WS-03 · 谁写的这个文件：第一眼要看所有权

**Web 服务的进程用哪个账号跑，它写出来的文件所有者就是谁。**

| 文件所有者 | 说明 |
| --- | --- |
| `www-data` / `nginx` / `apache` / `tomcat` | **web 服务自己写出来的** —— 攻击者通过上传漏洞传的，就是这个样子 |
| `root` | 要么是运维手动放的，要么是攻击者提权后放的 |
| 某个业务账号 | 业务程序写的，可能是正常的 |

## 为什么这条重要

**攻击者通过 web 上传漏洞传文件时，文件所有者必然是 web 进程的账号。**
这是物理决定的 —— 谁写的，文件就是谁的。

**所以：**

- 文件所有者是 web 进程账号 + 文件在 web 目录 → **高度可疑**（上传漏洞的典型形态）
- 文件所有者是 root + 文件不在 web 目录 → 更像运维操作

## ⚠️ 但「root 写的」不能洗白

攻击者拿到 root 之后写的文件，所有者也是 `root`。
**所以所有权只能用来区分「谁写的」，不能用来判断「是不是攻击者」。**
