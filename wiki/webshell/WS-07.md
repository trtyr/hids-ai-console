# WS-07 · 站点技术栈对不对得上

**一个 `.php` 文件放在一个只跑 Tomcat 的机器上 —— 它永远不会被执行。**

## 时间线怎么用

| 文件后缀 | 机器上应该有 | 对不上说明什么 |
| --- | --- | --- |
| `.php` / `.phtml` | PHP-FPM / Apache+mod_php | 没有 PHP 环境 → 这文件跑不起来 |
| `.jsp` / `.jspx` | Tomcat / Jetty / WebLogic | 没有 Java 环境 → 跑不起来 |
| `.asp` / `.aspx` | IIS | Linux 上没有 IIS → 跑不起来 |

**但注意**：跑不起来 ≠ 无害。它可能是攻击者放错位置的，也可能是下一步要装环境的。

**判据**：技术栈对不上 → 降级（从「真实威胁」降到「存疑」），但要写明为什么。
