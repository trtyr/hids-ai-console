# LP-08 · 提权之后干了什么：和别的类关联

## 提权之后干了什么

**单独一次提权很难定罪；提权之后的行为才是关键。**

### 要盯的后续（提权后 300 秒内）

| 后续 | 从哪个类看 |
| --- | --- |
| 可疑命令（`cloudwalker-suspicious-command`） | 这一类最直接 |
| 反弹 Shell（`cloudwalker-revshell`） | 提权后立刻连出去 |
| 恶意文件落地（`cloudwalker-malware`） | 提权是为了装东西 |
| WebShell（`cloudwalker-webshell`） | 提权是为了写 web 目录 |
| 网络外连（`cloudwalker-network-audit`） | 提权是为了横向 |

### 但「没看到」不等于「没有」

**攻击者可以等。** 提权之后什么都不做、过两小时再动手，是很常见的。

所以：

- **看到了后续 → 强证据，判真实威胁**
- **没看到后续 → 只是一个弱良性信号，不构成「确认安全」**

### 窗口怎么定

**300 秒**。理由和别的类一样：一次入侵动作的连贯操作通常在同一分钟内完成。
超过 5 分钟的间隔，关联强度就弱了。

> ⚠️ 但这条**只能当参考** —— 如果攻击者刻意等，300 秒窗口看不到任何东西。
> 所以判「误报」时不能只靠「窗口里没事」这一条。
