# RS-04 · 对端是谁：外网才是反弹，内网要分情况

## 对端是谁

`target_ip` / `target_port` 告诉我们这个 shell 连去哪了。

### 外网对端 → 反弹 Shell 的典型形态

攻击者控制一台外面机器，让受害主机连回去 —— 这样能绕过入站防火墙。

**所以「连到外网」是这一类的前提。**

### 内网对端 → 要分情况

| 内网对端是什么 | 意味着 |
| --- | --- |
| **运维跳板机 / 堡垒机** | 可能是正常运维通道（但**必须有登记**） |
| **同网段的另一台业务机** | 可能是横向 —— 这台已经被控制了 |
| 本机的其它容器 / 回环 | 可能是容器逃逸或本机服务 |

> ⚠️ **demo 里唯一那条反弹 Shell，对端是 `192.168.73.1`（内网）。**
> 这说明真实环境里内网对端的反弹 Shell 是存在的 —— 不能一律当外网处理。

### 端口能帮什么

| 端口 | 含义 |
| --- | --- |
| `4444` / `1337` / `5555` / `8080` / `9001` | **metasploit / 常见反弹端口**，加重 |
| `443` / `80` | 可能是伪装成 HTTPS，**不能因为像 web 就当良性** |
| 高位随机端口 | 中 |

**端口是加权项，不是判据。** 攻击者可以随便换端口 ——
Signal Fieldnotes 明确说「决定性的是通道和执行之间的关联，**不是端口**」。
