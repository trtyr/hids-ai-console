# RS-07 · syslog 和 API 各有什么

## syslog 和 API 各有什么

### syslog 侧（这一类的主力）

| 字段 | 是什么 |
| --- | --- |
| `source_ip` / `source_port` | 本机这一侧的地址端口 |
| `target_ip` / `target_port` | **对端**（连去哪了） |
| `protocol` | tcp / udp |
| `process_id` | 进程 PID |
| `process_command_line` | **命令行 —— 这一类最关键的字段** |
| `process_path` | 进程路径（**实测可能为空**） |
| `parent_process_pid` | 父进程 PID |
| `parent_process_cmdline` | **父进程命令行 —— 第二关键** |
| `parent_process_path` | 父进程路径（**实测可能为空**） |

### API 侧（补充）

| API 字段 | 等价于 |
| --- | --- |
| `remote_addr` / `remote_port` | `target_ip` / `target_port` |
| `owner` / `country_code` | 对端归属地、运营者 |
| `repair` | 这条连接已经持续多久 |

### 结论

**这一类的判据几乎全靠 syslog** —— 命令行 + 父进程命令行。
API 只补「对端归属地」和「持续时长」这两样辅助信息。

**所以 syslog 的 `process_command_line` 和 `parent_process_cmdline` 必须解析干净。**
这两个字段如果读丢了，整条告警就判不了了（只能存疑）。
