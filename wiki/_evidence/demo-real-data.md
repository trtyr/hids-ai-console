# demo 环境实测（我们自己的数据）

| 项 | 值 |

| 类型 | 自测 |

## 它说了什么

2026-11-02 ~ 11-04 对 demo 环境做的一批实测，构成了很多判据的**数量依据**：

| 类 | 实测 |
| --- | --- |
| WebShell | 5,544 条，**100% 是长亭 POC 测试文件**，一条真实攻击都没有 |
| 可疑命令 | 21,387 条，`iptables` 家族最大（8,823 条） |
| 恶意文件 | 3,756 条；180 条抽样里 108 docker 镜像层 / 54 `/proc/<pid>/exe` / 18 `/tmp` |
| 网络异常 | 20,230 条，500 条抽样**全是 type=dns**，其中 450 条是 `xxx.dnslog.cn` |
| 暴力破解 | 380 条事件，**`success_count` 全是 0**，19 个来源 IP 全在 CN |
| 本地提权 | 17,189 条**全部**是同一形态（`SUID提权 + dash + collie`） |
| 命令记录 | 只有 16 个会话 |
| 反弹 Shell | **只有 1 条**（对端 `192.168.73.1:4444`，内网） |
| 蜜罐 | 860~1,011 条；21~66 秒是深交互，1~6 秒是背景扫描 |

## 我们怎么用它

**这是最重要的一条证据** —— 它决定了哪些判据有真实数据支撑、哪些只能靠权威资料。
比如反弹 Shell 类（demo 只有 1 条）和内存两类（syslog 格式都没有），
判据基本全靠外部资料 + 构造样本，**这一点在 SOP 里必须写清，不能让人以为是从数据里挖出来的**。
