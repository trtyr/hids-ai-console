# 真实数据反查：样本比现实乐观（2026-11-04）

| 项 | 值 |
| --- | --- |
| 类型 | 自测 |
| 出处 | 本仓库 `sops/*/verify.py` + 直连 API 的字段比对 |
| 支撑的判据 | `SC-01`, `SC-10`, `GEN-03` |

## 它说了什么

不调模型、只跑 `collect_facts`（纯算术）对真实数据做的一次核对，查出：

1. 真实 `SuspiciousOperationService` 返回的字段里**没有任何 path / file 字段**；
   而我们的样本 S1 手工写了 `file_path` → **样本比现实乐观**。
2. 后果：20 条真实 iptables 事件**全被判「存疑」**（路径判不了），
   而同类样本判「误报」。
3. 修法：`file_path` 为空时，**从命令行第一个 token 兜底**。
   修完 20 条从「全存疑」变成「全误报」。

## 我们怎么用它

这条证据的价值不在结论，在**方法**：不烧 token 也能查出真问题。
同时它说明了一件事 —— **样本是我手工造的，可能带着我的假设**。
所以「92 条样本全过」不等于「真实数据上没问题」。
