# SC-03 · 执行路径不对：命令名对了，路径错了

系统命令**应该从它该在的地方跑**。同一个命令名，从异常路径跑，是强信号。

| 看到的 | 该在哪 | 判断 |
| --- | --- | --- |
| `find / ...` · path=`/usr/bin/find` | `/usr/bin/find` | 正常 |
| `./find /root -name id_rsa*` · path=**`/home/find`** | 系统目录 | **落地了同名二进制** |
| `./test/f -u https://...` · path=`/tmp/.../test/f` | 无 | 工具目录里的改名单文件 |
| `nc` · path=`/usr/bin/nc.openbsd` | `/usr/bin/` | 正常 |

**推论**：**path 字段要跟命令名一起看。** 命令名只说明「做了什么」，
路径说明「这东西是哪来的」。

> 依据：MITRE ATT&CK T1036 Masquerading —— 攻击者通过改名/改位置让恶意文件看起来像正常文件。
