# SC-08 · 摸安全软件：反侦察

> MITRE ATT&CK T1562.001 Impair Defenses: Disable or Modify Tools：
> 「This technique involves **disabling, modifying, or corrupting security software,
> forensic tools, or system utilities** to prevent detection and response.」

**含义**：`grep` 一个安全 agent 的路径，是**在确认装了哪些防御** —— 攻击者做这个是为了
知道「我的命令会不会被记下来」。

**但同样**：运维排查「云安全 agent 怎么没上报」也会 grep 同一个路径。

**判据**：grep 本身是**侦察**，不是攻击。**真正的攻击是「grep 完之后把 agent 停了」** ——
所以要看有没有后续的 disable / kill / uninstall 动作。

**⚠️ 「看不到后续」和「确认没有后续」不是一回事**（2026-11-02 实测踩过）：

| 情况 | 判法 |
| --- | --- |
| 窗口内**确实没有**后续处置动作（拿到了这条事实） | **误报** —— 一次孤立侦察 |
| 窗口内**没采到**任何数据（时间窗是空的、采集没覆盖） | **存疑** —— 因为「没看到」≠「没有」 |

> **判「误报」的前提是「窗口内确实没有」，不是「窗口内没采到」。**
>
> **demo 实测（290 条真实告警）**：全部是 `/usr/bin/grep` + **零会话痕迹**
> （无 SSH_CLIENT / SSH_TTY / PROMPT_COMMAND / XDG_SESSION_ID）
> —— 自动化任务或容器内跑的健康检查脚本，**不是人敲的**。
> 这种形态 + 窗口内确认无后续处置 → **孤立侦察 → 误报**。
>
> （⚠️ 但「零会话痕迹」本身**不能**单独定罪：WebShell 也在机器本地执行，
> 同样没有 SSH 痕迹。**必须配合「窗口内确认无后续」一起用。**）
