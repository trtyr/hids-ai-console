# SC-11 · 判定程序（可疑命令版）

**拿到一条可疑命令告警，按顺序走，第一个命中的就是结论。**

## 第 0 步 · 有没有真实威胁的硬证据？（排除性，先看）

出现以下之一 → **真实威胁**，直接结束：

- 矿工程序，且路径**不在**运维登记的测试工具目录里 —— SC-04
- 反弹 shell 的完整形态（`python3 -c import socket...` 连接外网 IP）—— SC-06
- **提权链成型**：`chmod +s` → SUID 枚举 → 落地可执行文件，秒级相连 —— SC-02 + SC-09
- **给系统自带命令加 SUID/SGID 权限**（如 `chmod +s /usr/bin/find`）—— SC-02
  → ⚠️ **这条不需要等链走完。** 判据见下面 SC-02 的补充说明。
- 落地了同名伪装二进制（命令名对、路径不在系统目录）—— SC-03

## 第 1 步 · 能排除真实威胁吗？

- 命令路径落在**运维已登记的测试工具目录**里 → SC-10 → **误报**
- 命令路径是系统标准路径 + 动作本身就是运维常规操作
  （iptables 改容器链、grep 查 agent 状态）→ **误报**

## 第 2 步 · 能给「误报」吗？

三条路径任一成立：

**路径 A · 我知道它是谁**
执行者是**运维登记过的操作人**，且动作在登记的操作范围内。
（登记在配置基线的 `authorized_operators` 里）

**路径 B · 我知道它在做什么**
命令本身**没有任何攻击语义**：

- 只是 `ls` / `cat` / `grep` 一个普通文件 / 查磁盘 / 看进程
- 命中规则，但动作的**唯一合理解释是运维**

### 路径 C · 我知道它没做什么

- 路径正常（系统目录里的标准命令）
- **这条命令本身没有攻击语义** —— 它不是在**留后门**（chmod +s 系统文件）、
  不是在**外联**、不是在**落地**、不是在**扫内网**、不是在**改持久化凭据**
- 前后没有关联的攻击动作（窗口内同会话没有接上任何一环）
- 执行者是运维账号，且该账号的历史判定都是误报

> ⚠️ **「枚举 SUID 程序」不在上面这份排除清单里** ——
> 也就是说 `find -perm -4000` **可以**走路径 C。
>
> **理由见 SC-02**：这条命令出现在每一份 Linux 加固清单里，
> 是**防守方的审计动作**。它只有在两种情况下才变成链上的一环：
> 前面有 `chmod +s`，或者后面接上了利用动作。
> **这两种都不满足时，它就只是一次排查。**
>
> （⚠️ 「枚举」要和「留后门」分开看：
> `chmod +s` 是**改**系统文件 → 有攻击语义，不能走路径 C；
> `find -perm -4000` 只是**看** → 审计动作，可以走路径 C。）

## 第 3 步 · 都不成立 → **存疑**

典型的不成立场景：

- 命令有攻击语义（挖矿 / 反弹 shell）**但路径和上下文解释不了**（既不是登记的测试工具，
  也不是运维账号做的）→ **存疑**，写清缺什么
- 命中了规则但**看不到完整命令行**（syslog 里 `process_command_line` 为空）→ **存疑**
- 前后有可疑关联但**间隔太长 / 语义对不上** → **存疑**

## 补充：**回连探测**（OUTBOUND_PROBE）单独一条，别混进上面三步

`ping` / `curl` / `nslookup` 一个 **dnslog / ceye / burp collaborator** 域名，
它的意思是「**确认这台机器能不能往外发请求**」——

- **DNS 回连域名本身没有正当用途**（SC-07）
- **但「试了一下」不等于「已经开始外传数据」**

所以要看**后续**：

| 情况 | 结论 |
| --- | --- |
| 单次回连，**会话内没有任何后续** | **存疑** —— 更像演练，但域名性质摆在那儿，不能直接放行 |
| 单次回连 **+ 后续接上了别的动作**（扫内网 / 挖矿 / 反弹 / 落地） | **真实威胁** |

> ⚠️ 这就是 S10 和 S11 的区别：**同一条 `ping xxx.dnslog.cn`**，
> S10 窗口里 `chain_relevant_events_in_session = 0` → 存疑；
> S11 窗口里接上了 3 条（扫内网 + 挖矿 + 回连）→ 真实威胁。
>
> **别看到 dnslog 就判真实威胁，也别看到「只是一次 ping」就判误报。**
