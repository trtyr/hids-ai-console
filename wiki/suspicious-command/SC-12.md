# SC-12 · 这三个事实层拿不到（先查 API，查不到才成立）

> ⚠️ **2026-11-03 改口径**：原来这一条叫「这三个事实层拿不到，必须承认」。
> 现在前面加一个动作：**先去 `SuspiciousOperationEventService` 查**。
> 能查到就不用「承认拿不到」。

| 拿不到 | 为什么 | 怎么办 |
| --- | --- | --- |
| **命中的是哪条规则** | syslog 字段表里**没有 `rule_name`**，只有 `event_name` | 从 `event_name` 里解析（形如「发现可疑操作，XXX」）；解析不出来就标记「规则名未知」，**不要猜** |
| **父进程是谁** | syslog 的 `process_tree` 是 JSON 字符串，但 API 侧的 `signature.pexename` 在 demo 里**全为空** | 只能用 `process_tree`；它为空就说「父进程未知」，**不许用进程名反推** |
| **文件内容** | WebShell/恶意文件类才有；可疑命令类没有 | 不适用 |

**依据**：GEN-03「缺信息要明说，不要用猜的填」。
