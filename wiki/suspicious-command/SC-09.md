# SC-09 · 命令序列的语义连贯（这一类的核心判据）

**这是可疑命令和其他 11 类最大的不同。**

蜜罐类的判据是「谁在碰我」。可疑命令类的判据是「**这几条命令串起来在干什么**」。

**demo 里的实证（三次独立发生，间隔 26s / 5s / 2s）**：

```text
11:39:47  chmod +s /usr/bin/find          ← 给系统 find 加 SUID（留下后门）
          ↓ 26 秒
11:40:13  find / -user root -perm -4000    ← 枚举所有 SUID 程序（找提权点）
          ↓ 5 秒
11:40:18  ./test/bminer                    ← 三个矿工同时起（偷算力）
11:40:18  ./test/nbminer
11:40:19  ./test/ethminer
          ↓ 2 秒
11:40:21  ./test/f -u https://www.xyz.com -proxy 8080   ← fscan 内网扫描
```

**单看每一条都可以解释成良性的**：

- `chmod +s` = 装软件
- `find -perm -4000` = 排查
- 矿工 = ？（这个已经是硬证据了，但可以是「公司在挖矿」）
- fscan = 内网扫描工具

**串起来只有一个解释。**

**判据（按顺序）**：

1. **时间方向 + 秒级间隔** —— 26 秒、5 秒、2 秒。不是分钟级，不是小时级。
2. **语义方向一致** —— 提权 → 找提权点 → 用算力 → 扫内网，全是「攻击者控制这台机器之后会做的事」。
3. **同一条登录会话** —— `SSH_CLIENT` 相同，说明是**同一个人/同一个会话**连续干的。

**满足 1 + 2 → 足以支撑「真实威胁」**，不必再找到「同源标识贯穿」。
