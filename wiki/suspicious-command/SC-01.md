# SC-01 · 双用途工具：命令本身不能定罪

> Elastic Security《File Transfer or Listener Established via Netcat》：
> 「Netcat is a **dual-use** command line tool that can be used for various purposes,
> such as **port scanning, file transfers, and connection tests**. Attackers can abuse
> its functionality for malicious purposes such **creating bind shells or reverse shells**
> to gain access to the target system.」

**含义**：同一份命令，攻防两边的形态**完全一样**。

| 命令 | 运维在做 | 攻击者在做 |
| --- | --- | --- |
| `nc -lp 4444` | 起个监听测连通性 | 开 bind shell |
| `python3 -c import socket...` | 本地调试脚本 | 反弹 shell |
| `find / -user root -perm -4000` | 排查系统里哪些程序有 SUID | 找提权点 |
| `chmod +s /usr/bin/find` | 修某个程序的权限 | 给后门加 SUID |
| `grep /usr/local/qcloud/.../sgagent` | 确认云安全 agent 在不在 | 摸清装了哪些防御 |
| `iptables -I FORWARD -j DOCKER-USER` | 容器网络配置 | 改防火墙策略 |

**推论**：**「命中了可疑规则」本身不是证据。** 判据必须落在
**执行上下文**（谁执行、从哪来、路径对不对、前后干了什么）上。
