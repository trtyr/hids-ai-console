# 规则页设计稿 · 开发交接说明

对应文件：`rules.html`
入口：左侧导航「规则」

---

## 1. 页面职责

维护「前置规则」配置：在自动研判流程之前生效、带 revision 版本与只读标记的规则集。文档只把 `config` 定义成自由对象，没有字段说明，因此页面不预设规则字段，而是**按真实 config 自动生成表单**，同时保留 JSON 视图。

示例配置为空对象 `{}`，不编造 `rules`、`version` 之类的结构；后端返回什么，表单就长什么样。

---

## 2. 结构

```
顶栏：规则 · 刷新 · 主题
主区左侧：
  头部：前置规则 · revision · 可写/只读 · 未保存 · 表单/JSON 切换 · 撤销 · 复制
  表单视图：按 config 递归生成的对象 / 数组 / 值控件
  JSON 视图：行号 + 等宽文本域
  底部：JSON 状态 · 光标行列（JSON 视图）
右侧：
  状态：config 结构说明、revision、可写、条目数
  校验：校验按钮 + 结果
  保存：expected_revision、管理令牌、保存按钮、说明
  操作日志
```

### 表单能做什么

- 对象：每个字段一行，可改字段名、改值、删除；底部「添加字段」可选字符串 / 数字 / 布尔 / 对象 / 数组。
- 数组：每项可上移、下移、删除，底部「添加一项」。
- 嵌套对象与数组默认折叠，标题显示字段数 / 项数。
- 布尔用勾选框，数字用数字框，字符串用文本框；`null` 原样显示，不提供类型转换。
- 所有操作只改本地模型，点保存才提交。

---

## 3. 数据映射

| 界面元素 | 接口字段 |
| --- | --- |
| revision | `GET /api/triage/rules` → `revision` |
| 可写 | `writable` |
| 表单 / JSON 内容 | `config`，表单由它递归生成，JSON 视图为其格式化文本 |
| 保存 | `PUT /api/triage/rules`，body `{ config, expected_revision }`，header `X-Rule-Admin-Token` |
| 校验 | `POST /api/triage/rules/validate`，body `{ config }` → `{ valid, count }` |
| 条目数 | 校验返回的 `count`（含义由后端定义；示例不返回，显示「—」） |

### 视图同步

- 表单修改后切到 JSON：按当前模型重新格式化。
- JSON 修改后切到表单：解析成功才切换并重建表单；语法错误时停在 JSON 视图并提示。
- 校验与保存都以当前模型为准；JSON 视图语法错误时拒绝执行。

---

## 4. 交互与状态

| 状态 | 触发方式 | 呈现 |
| --- | --- | --- |
| 空配置 | config 为 `{}` | 表单显示空对象说明、添加字段行和 JSON 入口 |
| 编辑 | 表单或 JSON | 未保存标记出现，撤销 / 保存按条件启用 |
| 字段重命名 | 修改字段名后失焦 | 空名或重复名被拒绝并记录日志，恢复原名 |
| 校验 | 点击校验 | 语法错误就地提示；通过时显示「校验通过」，条目数留空等真实接口 |
| 保存成功 | 填写令牌后保存 | revision 更新，未保存标记消失，日志记录 |
| 令牌错误 | 令牌不等于演示值 | 403 提示，编辑内容保留 |
| 只读 | `writable=false` | 表单置灰不可操作、JSON 只读、保存禁用 |
| 撤销 / 刷新 | 顶部按钮 | 撤销回到上次保存；刷新重新读取并丢弃未保存修改 |
| 复制 | 顶部复制 | 复制当前模型的格式化 JSON |
| 未定稿页面 | 知识库导航 | 占位页与返回 |

### 演示约定

- 没有真实后端：校验只模拟「通过」，不编造条目数；保存令牌为 `admin-token`，错误令牌模拟 403；保存成功生成新的 revision。
- 初始 `config` 为空对象，不预设任何规则字段。

---

## 5. 已知限制

- `config` 的结构与语义未定义，页面没有规则专用控件（如告警类型、阈值、白名单）；需要后端 schema 后再做。
- `null` 只能查看不能编辑；不支持字符串 / 数字 / 布尔之间的类型转换，需要删除后重加。
- 数组排序只支持上移 / 下移，没有拖拽；嵌套层级很深时表单会变长。
- `expected_revision` 的 409 / 428 冲突分支尚未模拟。
- 文档只写「前置规则」，没有说明它参与告警过滤还是自动研判准入，页面文案保持中性。

---

## 6. 响应式与主题

- ≥ 900px：编辑器 + 320px 操作栏，页面锁在一屏内，表单与 JSON 内部滚动
- ≤ 900px：上下排列，表单区域 52vh，页面允许纵向滚动
- ≤ 620px：表单行改为单列、字段名独占一行；隐藏 JSON 行号
- 深色 / 浅色共用 `assets/theme.css` 与 `assets/theme.js`
