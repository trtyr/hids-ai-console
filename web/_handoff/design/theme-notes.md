# 主题系统说明 · 深色 / 浅色

对应文件：`assets/theme.css`（token 与切换按钮样式）、`assets/theme.js`（初始化与切换）

已接入的页面：`index.html`、`overview.html`、`alerts.html`、`alert-detail.html`、`trace.html`、`rules.html`、`wiki.html`。

---

## 1. 切换方式

- 顶栏右侧是一个只有图标的按钮（30×30）：深色下显示太阳，浅色下显示月亮，点击切换到另一套主题。
- 按钮不带文字，鼠标悬停显示提示「切换到浅色模式 / 切换到深色模式」，读屏播报同一句。文件名、位置与其它工具按钮对齐，不再占用一个带边框的文字胶囊。
- 首选读取 `localStorage` 的 `hids-theme`；没有记录时跟随系统 `prefers-color-scheme`，系统不支持则默认深色。
- 用户手动切换后写入本地，之后所有页面沿用。
- `assets/theme.js` 在 `<head>` 内同步执行，先写 `data-theme` 再渲染，避免首屏闪白。
- 按钮有动态 `aria-label` 与 `title`；`localStorage` 不可用时只切换当前页，不报错。

---

## 2. 接入方式（后续页面照做）

```html
<link rel="stylesheet" href="assets/theme.css" />
<script src="assets/theme.js"></script>
```

页面自身的 `:root` 只保留字体、间距、圆角、动效，不再声明颜色；所有颜色写 `var(--…)`。切换按钮结构：

```html
<button type="button" class="theme-toggle" data-theme-toggle>
  <svg class="icon-sun">…</svg>
  <svg class="icon-moon">…</svg>
  <span data-theme-label>浅色</span>   <!-- 样式里已隐藏，仅给脚本同步状态 -->
</button>
```

按钮宽高 30×30、透明底、悬停时才出现底色，与顶栏里的文字按钮同一层级；不要给它加边框或文字，否则会和状态胶囊混淆。登录页没有顶栏，按钮用 `class="theme-toggle theme-toggle--float"` 固定在右上角（34×34，带细边框）。

## 3. 主题取值与对比度

深色为石墨灰而不是纯黑：页面底 `#171b1c`、面板 `#1e2425`、主色 `#64b6a0`；浅色按用户要求改成米色纸面：暖沙色页面底 `#ece5d8`、象牙色面板 `#f9f4e9`、深青主色 `#1c6f5c`。两套都不使用纯黑或纯白。关键组合（WCAG 2.x，正文需 ≥ 4.5:1）：

| 组合 | 浅色 | 深色 |
| --- | --- | --- |
| 正文 / 页面底 | 13.1 : 1 | 13.9 : 1 |
| 次级文字 / 页面底 | 6.1 : 1 | 8.1 : 1 |
| 辅助文字 / 页面底 | 5.2 : 1 | 5.7 : 1 |
| 弱化文字 / 页面底 | 4.6 : 1 | 5.4 : 1 |
| 主色文字 / 面板 | 5.5 : 1 | 6.6 : 1 |
| 主按钮文字 / 主色底 | 6.0 : 1 | 7.9 : 1 |
| 危险色 / 面板 | 6.2 : 1 | 4.8 : 1 |
| 警示色 / 面板 | 6.1 : 1 | 6.3 : 1 |

主色在浅色下取 `#1c6f5c`，深色下取 `#64b6a0`；按钮文字反色分别用白和深墨。米色为用户明确指定，属于对默认反米色约束的主动覆盖；后续新页面直接沿用这套 token，不要再写纯白。

---

## 4. 按主题重新取值的细节

- 选中行、导航选中、悬停底色：浅色用暖米色阶，不直接反色。
- 复选框勾与半选横线：通过 `--check-icon` / `--dash-icon` 两套内联 SVG，浅色下用白勾。
- 危险 / 警示提示条：浅色用浅暖底 + 深色文字，深色用深底 + 亮色文字。
- 弹窗与抽屉遮罩：浅色约 30% 暖黑，深色约 72% 黑。
- 登录页链路底图、测量网格：浅色下改用深暖色低透明度线条。
- 原生控件通过 `color-scheme` 跟随主题，下拉框、滚动条不再出现深色控件浮在浅色页上的情况。

---

## 5. 已知限制

- 主题跟随系统只在首次访问（无本地记录）时生效，之后以用户手动选择为准。
- 切换不会重新加载页面，图表与 SVG 使用 `currentColor`，无需重绘。
- 若后续新增页面直接写死颜色，浅色下会不一致；接入时请只使用 `theme.css` 中的变量。

---

## 6. 文件清单

- `assets/theme.css`：深色 / 浅色两套 token、切换按钮样式。
- `assets/theme.js`：初始化、持久化、按钮状态同步。
- 四个页面：移除各自的颜色声明，改用共享 token，并加入切换按钮。
