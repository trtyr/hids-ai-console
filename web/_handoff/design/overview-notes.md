# 总览页设计稿 · 开发交接说明

对应文件：`overview.html`
关联页面：`index.html`（登录成功后进入此页）

---

## 1. 页面职责

登录后的值班台，只看"现在什么情况"：告警量、类型分布、自动研判队列、依赖状态。告警明细不在这页出现——列表、详情、入队操作都属于「告警」页，避免总览页变成一个半成品列表。

示例数据集中在脚本顶部的 `DATA` 对象里，接真实接口时整体替换，渲染函数不用改。

---

## 2. 结构

```
左侧导航 196px │ 顶栏：页面标题 · 更新时间 · 刷新
               │ 摘要带：告警总数 / 待研判 / 研判中 / 失败 ＋ 右侧 11 段类型构成条
               │ ┌ 事件类型（11 行：类型 / 数量 / 占比 / 分布条）
               │ └ 侧栏：自动研判（状态、输入方式、最近轮询、四项计数、最近错误）
               │          运行状态（牧云、模型、规则、取证工具、提示词、版本）
               │ 底部：研判进度（完成 / 待研判 / 研判中 / 失败 的占比条与图例）
```

- 摘要带四个数字之间只有竖发丝线，数字 23px，标签在其上方。
- 事件类型是一张完整的表：类型在左，数量与占比右对齐，最后一列是 4px 占比条，便于纵向比较。
- 侧栏两模块都是键值行（label 左、值右），没有卡片底色与边框。
- 摘要在数字右侧放一条 11 段构成条，段落宽度按类型数量分配，下方写当前最多的三类；它只做概览，详细数字仍在事件类型表里。
- 底部研判进度条按队列四项计数分段，图例给出数量与百分比，完成率由后端计数算出。
- 页面按一屏高度安排：顶栏 52、摘要带、两栏主体、进度条；窄屏才允许纵向滚动。
- 全页没有弹窗与行内操作，所有写操作留在「告警」页（研判状态与队列开关已并入该页）；本页只保留一个队列暂停/恢复。

---

## 3. 视觉决定的由来

上一版看起来像模板生成物，主要来自这些做法，本版已全部移除：

- 三张带圆角与边框的同质卡片 → 无卡片，用横向排线分区
- 54px 大号数字 → 23px 数字，靠对齐和留白建立层级
- 11 个相同的小方块矩阵 → 一张完整的数据表
- 每个状态一个带圆点的胶囊 → 状态文字 + 5px 方块
- "点击筛选右侧列表""按占比排列"这类解释文案 → 删除，信息自解释
- 圆角 8–10px、多处强调色 → 圆角 0–2px，强调色只用于选中态与可点击文字

## 4. 数据映射

| 界面元素 | 接口字段 |
| --- | --- |
| 告警总数 | `overview.alerts.total`（示例中等于 11 类之和：347） |
| 类型表 | `overview.alerts.totals[...]` 的 11 个类型字段 |
| 部分失败提示 | `overview.alerts.partial`、`overview.alerts.errors` |
| 待研判 / 研判中 / 完成 / 失败 | `overview.triage.counts.queued / running / done / failed` |
| 队列状态与暂停 | `overview.triage.enabled`（对应 `PUT /api/agent/triage/control`） |
| 输入方式 | `overview.triage.input_mode` |
| 最近轮询 | `overview.triage.last_poll_at` |
| 取证工具 | `/api/agent/tools` 的 `count` |
| 提示词版本 | `/api/agent/status` 的 `prompt_version` |
| 最近错误 | `overview.triage.last_error` |
| 更新时间 | `overview.checkedAt` |
| 运行状态 | `/api/status.connected`、`/api/agent/status.configured`、`/api/triage/rules.revision`；字段为空显示「—」，不再写死「已同步」 |
| 版本 | `/api/updates.revision` |

告警总数与队列计数是两套独立统计，不要求相加相等。

## 5. 交互与状态

| 状态 | 触发方式 | 呈现 |
| --- | --- | --- |
| 默认 | 打开页面 | 渲染摘要、类型表、队列与运行状态 |
| 刷新中 | 点击刷新 | 按钮禁用并旋转，内容区降低透明度，完成后更新时间并读屏播报 |
| 部分失败 | `partial=true` | 摘要带上方出现一行警示，说明总数只合计成功类型 |
| 队列暂停 | 点击暂停 / 恢复 | 状态文字与方块转警示色，按钮文案同步，读屏播报 |
| 未设计页面 | 点击其他导航项 | 主区显示占位与返回按钮，导航选中态同步 |

本页没有行级操作：类型行不可点击，告警明细与入队统一去「告警」页处理。

---

## 6. 响应式

- ≥ 1100px：左侧 196px 完整导航，右侧栏 300px
- ≤ 1100px：导航收为 56px 图标栏，侧栏收窄到 260px
- ≤ 900px：导航变为顶部横向条，账号区块隐藏，退出登录保留在右侧
- ≤ 820px：两侧栏改为单列，自动研判与运行状态并排为两栏
- ≤ 760px：隐藏细分隔列与更新时间
- ≤ 620px：摘要数字转为两行两列，侧栏两模块改为上下排列
- 页面最小宽度 320px，无横向滚动
