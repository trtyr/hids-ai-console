# 深度溯源页设计稿 · 开发交接说明

对应文件：`trace.html`
入口：
1. 左侧导航「深度溯源」→ 左侧白板列表，选中后在画布打开；
2. 告警详情「深度溯源」→ `trace.html?target=<告警 ID>`，命中已有白板则直接选中，否则预填目标。

---

## 1. 页面职责

以 Obsidian 关系图的方式看溯源过程：节点是小圆点加标签，关系是细线，没有卡片、没有字段行；节点随调研一步步出现，相关的才连线。

---

## 2. 结构

```
顶栏：深度溯源 · 刷新 · 主题
左侧：白板列表 + 新建目标
右侧：
  画布顶栏：白板 ID · 状态 · 节点 / 关系数 · 回放控制 · 缩放
  画布：点阵背景、圆点节点、细线关系
  检查器：未选中时显示白板摘要、缺口与「调研过程」时间线；
          选中节点 / 连线时显示该对象的全部字段
```

- 节点：9px 实心圆点 + 11px 标签，选中时圆点变强调色并带一圈淡光。
- 关系：1.2px 细线，带箭头与关系文字（取 `label / relation / relationship / type / kind`），选中时线、箭头、文字一起变强调色；完整字段在检查器里看。
- 画布背景是低对比点阵，缩放与平移只作用于画布内容。

---

## 3. 渐进显示规则

- 节点按「调研顺序」逐个出现，每 900ms 一个；最新节点做淡入缩放，连线同时淡入。
- 调研顺序优先取 `activity[]` 中引用了节点的记录，其次按 `nodes[]` 原顺序补齐。
- 连线在两个端点都出现后才绘制：先有 A，再发现相关的 B，就出现 A→B；与 A 无关的 C 单独出现，没有连线。
- 完成态白板打开时也会从第一个节点重放，可随时「跳到最新」。
- 播放结束后自动适应全图。

---

## 4. 交互

| 操作 | 行为 |
| --- | --- |
| 拖拽空白处 | 平移画布 |
| 滚轮 | 以指针为中心缩放（25%–250%） |
| 拖动节点 | 移动圆点，连线实时跟随；拖动时自动暂停回放 |
| 悬停节点 | 圆点与标签提亮 |
| 点击节点 / 连线 | 选中，检查器显示全部字段 |
| 点击调研过程条目 | 定位到对应节点（未出现的条目禁用） |
| 重放 / 暂停 / 继续 | 控制渐进显示 |
| 跳到最新 | 一次显示全部已返回节点与关系 |
| 跟随 | 开启时每个新节点自动居中；关闭后保持当前视图 |
| 新建 / 切换白板 | 从第一个节点重新播放 |
| 刷新 | 重新渲染并适应视图 |

## 5. 数据映射与解析

| 界面元素 | 接口字段 |
| --- | --- |
| 白板列表 | `GET /api/trace/boards` → `boards[]` |
| 新建 | `POST /api/trace/boards`，`target` 支持告警 ID / IPv4 / `ip:` 前缀 |
| 白板详情 | `GET /api/trace/boards/{target}` |
| 概览 | `TraceBoard.summary`、`gaps`、`status` |
| 节点 / 关系 / 活动 | `TraceBoard.nodes`、`edges`、`activity`（元素均为自定义 object） |
| 节点引用（调研顺序） | 尝试读取 activity 元素的 `node / node_id / nodeId / 节点` |

由于内部字段未定义，图谱使用通用解析：

- 节点位置：有 `x` / `y` 就用；没有则用前端力导向布局计算（斥力 + 连线引力 + 向心），属于展示层。
- 节点标识：优先 `id`，其次 `key` / `uuid`。
- 节点标签：优先 `label` / `name` / `title`，缺失时显示「节点 N」。
- 连线端点：在边对象里查找 `source / from / fromNode / src / start` 与 `target / to / toNode / dst / end`，值能匹配节点标识或标题才绘制。
- 节点与连线的全部字段都在检查器里原样展示。

### 已知限制

- 上述解析是临时适配，不是接口契约；字段定义后应替换为明确解析。
- 力导向布局每次加载重新计算，拖动位置只在当前会话生效。
- 关系没有端口概念，多连线没有避让；连线文字只取第一个可用的关系字段，不拼接多条。
- 「新建」只创建本地示例任务，没有真正发 `POST`，也没有轮询进度。
- 调研顺序依赖 activity 里的节点引用；没有引用时退化为数组顺序。

---

## 6. 响应式与主题

- ≥ 900px：左侧列表 236px，检查器 280px，画布占剩余空间
- ≤ 900px：列表变为横向卡片条，画布 60vh，检查器落到下方
- ≤ 620px：画布 52vh，控制按钮加大触控高度
- 深色 / 浅色共用 `assets/theme.css` 与 `assets/theme.js`；圆点、连线、点阵背景都取主题变量
