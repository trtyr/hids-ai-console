# 登录页设计稿 · 开发交接说明

对应文件：`index.html`（单文件可运行，含内联样式与交互脚本）
字体资源：`assets/fonts/`（Space Grotesk / JetBrains Mono 本地 woff2 子集，SIL OFL 1.1）

---

## 1. 页面定位

这是产品登录页，只承担一件事：让已授权的人进入工作台。因此页面上不出现功能介绍、能力清单、接口路径、协议名称、探测状态或版本对比——这些属于官网和内部文档，不属于登录入口。

页面只有三层信息：品牌（标识 + 名称）、登录卡片、页脚（使用范围 + 版本）。维护端是独立服务、独立入口，不在本页出现。

---

## 2. 结构

左右分栏，左品牌、右登录：

- 左侧品牌区（约 54%，稍深一层的底色，右侧一条发丝分隔线）只放三样东西：顶部品牌锁定（标识 + `HIDS` + 分隔线 + `AI 研判平台`）；中部一句立场文案「告警是起点，结论才是答案。」；底部一行使用范围与版本号，与右侧内容底边齐平。
- 左侧背景：极淡测量网格 + 代码绘制的攻击链路底图（节点、连线、虚线、雷达圆），透明度很低，只营造“溯源”的气质，不承载任何文案或数据。
- 右侧登录区：396px 宽的卡片在栏内垂直居中，卡片下方一行演示账号标注。
- 整页无图片资源，底图与图标均为内联 SVG。

## 3. 交互与状态

| 状态 | 触发方式 | 呈现 |
| --- | --- | --- |
| 默认 | 打开页面 | 账号输入框自动获得焦点，主按钮为强调色 |
| 字段校验 | 输入框失焦且为空 | 字段下方红字提示 + 输入框错误边框 + `aria-invalid` |
| 登录中 | 提交且本地校验通过 | 按钮禁用、显示旋转指示、文案「正在登录…」 |
| 登录失败 | 账号或密码不匹配 | 卡片内错误横幅，提示剩余可尝试次数，密码清空并回焦 |
| 频率限制 | 连续 3 次失败 | 横幅转为警示色，按钮显示「N 秒后可重试」并禁用，30 秒后自动恢复 |
| 无法连接 | 提交时浏览器离线 | 横幅提示检查网络或稍后重试 |
| 登录成功 | 使用演示账号提交 | 表单替换为已登录摘要：账号、登录时间、退出登录 |
| 退出 | 点击「退出登录」 | 回到表单，清空密码与错误，焦点回到账号 |

演示账号（仅前端模拟）：`hids` / `hids-2026`。

频率限制是本稿在客户端模拟的节流行为，用于呈现受限状态；业务接口本身只返回 401，接入真实接口时按服务端策略决定是否保留。

## 4. 设计 token

### 色彩

| 变量 | 深色值 | 用途 |
| --- | --- | --- |
| `--ink-900` | `#171b1c` | 页面底色（右侧登录区） |
| `--ink-800` | `#1b2021` | 左侧品牌区底色 |
| `--ink-700` | `#1e2425` | 登录卡片 |
| `--line` / `--line-2` | `#2c3435` / `#3d4849` | 发丝分隔线 / 强分隔线 |
| `--text` | `#e2e7e8` | 主文本 |
| `--text-2` | `#a9b3b5` | 次级文本 |
| `--text-3` | `#8a9699` | 辅助说明、页脚 |
| `--accent` | `#64b6a0` | 唯一信号色：主按钮、焦点、登录成功 |
| `--accent-ink` | `#08130f` | 强调色上的文字 |
| `--danger` | `#d47362` | 字段错误、登录失败 |
| `--warn` | `#c99d57` | 频率限制、网络异常 |

这些颜色已统一放到 `assets/theme.css`，浅色值在同文件覆盖；两套对比度与切换方式见 `theme-notes.md`。正文与辅助文本均按各自底色单独核算，对比度 ≥ 4.5:1。

### 字体

- 界面：`SpaceGrotesk` → 系统中文（PingFang SC / Noto Sans SC / Microsoft YaHei）
- 数字、登录时间、版本号：`JetBrainsMono`，开启等宽数字
- 字号：卡片标题 19px；输入框 15px（移动端 16px）；标签 13px；辅助说明与页脚 10.5–11.5px；行高 1.6–1.7

### 间距、圆角、动效

- 间距为 4px 基数：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48
- 圆角：4（徽标）/ 8（控件）/ 10（卡片）
- 动效：品牌与卡片入场 320ms `ease-out`，依次延迟 0 / 60ms；错误横幅 160ms；仅动 `opacity` 与 `transform`
- `prefers-reduced-motion: reduce` 下全部动画降为瞬时

### 图标

眼睛、锁、勾选为功能性图标，统一 1.2–1.6 描边，通过 `.od-icon` 与 `--od-icon-size` 控制尺寸；品牌标识与雷达弧线为内容图形，独立 `viewBox`。

---

## 5. 断点

- ≥ 1180px：左右分栏，左栏文案完整字号显示
- 960–1180px：左右保留分栏，左栏文案缩小到 34px 上限，右侧内边距收窄
- ≤ 960px：单列，左栏收缩为顶部品牌条（标识 + 名称），文案、底图、页脚隐藏，登录卡片进入首屏
- ≤ 720px：卡片宽度跟随屏幕（最大 420px）、内边距 20px、输入框 16px 字号、显示切换按钮 44px 高
- ≤ 400px：隐藏品牌副标题，保留标识与 `HIDS`
- 页面无横向滚动；内容不足一屏时右栏垂直居中，超出时正常滚动

## 6. 接真实接口的替换点

1. 删除 `DEMO` 常量、演示账号标注与本地比对，改为提交 `fetch('/api/session', { credentials: 'include' })`；业务端未启用 Basic 认证时该请求会直接成功。
2. 失败走 `401` 分支：清空密码、显示错误横幅；`/api/session` 返回 404 表示路由版本差异，可降级用 `GET /api/agent/status` 探测，但不要把这类技术细节呈现给用户。
3. 登录成功后跳转控制台，而不是停留在「会话已建立」摘要；摘要只用于本设计稿验证状态。
4. 是否需要频率限制由服务端策略决定，本稿的 30 秒为演示值。
5. 用户名、帮助文案、版本号、页脚使用范围文案请按实际产品规范替换（当前版本号取自接口文档信息段）。

---

## 7. 说明

- 页面为纯前端设计稿，不含真实认证。
- 深浅两套主题由 `assets/theme.css` 提供，右上角可切换，选择会记忆；浅色为米色纸面（用户指定），两套对比度分别核算，详见 `theme-notes.md`。
- 未使用外部图片、图床或 CDN 依赖，字体已本地化，可在内网离线环境直接打开。
- 左侧攻击链路底图为内联 SVG，颜色跟随强调色，透明度通过分组控制，后续可直接替换节点坐标或用真实数据驱动。
- 未提供「忘记密码」「注册」「SSO」入口，因为接口未定义相应能力；后续若补齐能力再增加入口。
