# 知识库页设计稿 · 开发交接说明

对应文件：`wiki.html`
入口：左侧导航「知识库」

---

## 1. 页面职责

知识库由两屏组成，沿用平台其它页面的同一套骨架：

- **条目列表**：搜索、分类筛选、标签筛选，表格列出全部页面。
- **条目页**：标题、元信息、摘要、目录、分节正文、分类；右侧是条目信息、相关条目、接口字段；「编辑」页签改草稿。

排版与其它页面一致：13px 正文、发丝分隔线、等宽数字、单一主色、0–2px 圆角，不引入第二套视觉语言。

---

## 2. 结构

```
侧栏 196px：品牌 · 导航（总览 / 告警 / 深度溯源 / 规则 / 知识库）· 账号 · 退出
顶栏 52px：知识库 · 共 N 条 · N 份本地草稿 · 更新时间 · 刷新 · 主题

条目列表（默认视图）
  筛选条：搜索（标题 / 编号 / 路径 / 分类）· 分类下拉 · 标签下拉 · 清除筛选 · N / 10 条
  表格：条目（标题 + 摘要）· 分类 · 编号（等宽）· 状态 · 分节数
  空态：没有匹配的条目

条目页
  面包屑：知识库 / 分类 / 编号
  头部：分类 · 状态 · 编号 ｜ 条目/编辑切换 · 复制路径 · 提交审核
        标题（21px 600）· 路径 · 分节 · 字数 · 最后修改 · 正文来源 · 未保存提示
  正文列：摘要、目录（章节锚点）、分节正文（每节标题右侧「编辑」）、分类
  右侧栏：条目信息（键值）、相关条目（同分类，最多 4 条）、接口字段（折叠 JSON）

编辑页签
  标题输入 · 分类标签增删 · 正文 Markdown 文本域
  页脚：字数 · 保存状态 · 撤销修改 · 保存草稿
```

---

## 3. 数据边界

| 内容 | 来源 |
| --- | --- |
| 标题、编号、路径、状态 | `GET /api/wiki/pages` 的 `pages[]`（`id / path / title / status`） |
| 正文 | 接口未定义正文字段 → 本地示例草稿 |
| 分类标签 | 接口未定义标签字段 → 本地示例草稿 |
| 保存 | 浏览器本地（`hids-wiki-drafts`），接口没有更新页面的能力 |
| 发布 | 只能走知识维护会话（`POST /api/wiki/sessions`）＋ 人工审核 |

界面按实际来源标注：条目页写「正文来源：示例草稿（接口未定义）」或「本地草稿」，最后修改时间只在保存草稿后出现，未保存时不编造时间。

---

## 4. 交互与状态

| 场景 | 行为 |
| --- | --- |
| 打开页面 | 默认进入条目列表，焦点在搜索框外，不抢焦点 |
| 搜索 / 筛选 | 即时过滤表格，右侧显示「N / 10 条」；有筛选时出现「清除筛选」 |
| 点击条目 | 打开条目页；有未保存草稿时先确认 |
| 面包屑 | 「知识库」回列表并保留筛选；分类项筛到该分类 |
| 目录 | 点击滚动到对应小节 |
| 小节「编辑」 | 切到编辑页签并把光标定位到该节所在行 |
| 内链 `[[编号]]` | 点击切换条目；未建页的显示红色虚线，不跳转 |
| 相关条目 / 分类 | 点分类回列表并按该标签筛选；点相关条目直接打开 |
| 编辑 / 条目 | 页签切换，未保存修改保留在编辑视图 |
| 保存草稿 | 写入本机，刷新字数、分节、最后修改、来源标注与草稿计数 |
| 撤销修改 | 回到上次保存的草稿 |
| 复制路径 | 写入剪贴板并提示 |
| 提交审核 | 校验修改原因（失焦后校验），创建会话并提示；失败原因就地显示 |
| 刷新 | 重新渲染当前视图，保留未保存修改 |
| 离开未保存 | 弹窗：保存并离开 / 放弃修改 / 取消 |

---

## 5. 已知限制

- 正文、标签字段未定义，也没有更新页面的接口，草稿只在本机；发布走维护会话。
- 没有新建 / 删除 / 重命名页面的接口，页面不提供这些入口。
- 搜索与筛选在本地示例目录上完成；真实接口支持 `q` 参数，接入时改为请求。
- 没有历史版本与讨论页：文档无对应接口，界面不放假页签。
- 相关条目按本地分类标签推算，不是后端关系数据。
- `/api/wiki/health`、维护会话列表 / 消息 / 重放 / 发布未接入。

---

## 6. 响应式与主题

- ≥ 1180px：正文列 + 288px 右侧栏。
- 1100px 以下：侧栏收成 56px 图标栏。
- 900px 以下：侧栏变顶部横条，正文与右侧栏单列堆叠，表格隐藏分类与编号列。
- 620px 以下：搜索独占一行，表格再隐藏状态列，按钮触控高度加大。
- 深色 / 浅色共用 `assets/theme.css` 与 `assets/theme.js`，切换在顶栏右侧。
